## 1. 人気タイトルと「効いている仕組み」

| タイトル | 中核の仕組み | 学ぶべき点 |
| --- | --- | --- |
| **Finch** | 現実のセルフケア習慣達成 → ペットが冒険して成長・お土産を持ち帰る | 「お世話」を作業ではなく**ユーザ自身の生活の報酬**に変換した。低プレッシャーで罪悪感を作らない |
| **たまごっち（Tamagotchi Uni / Tamaverse）** | 放置ペナルティ（ケアトリガー）＋通信によるアイテム交換・結婚・世代交代 | **生存プレッシャー**が最強のリテンション。ただし現代では緩和が必須。世代交代がストーリーを生む |
| **ねこあつめ / ねこあつめ2** | 完全放置。エサとグッズを置いて、非同期に猫が勝手に来てお礼（たからもの）を残す | **非同期のサプライズ**＝ガチャ的ランダム報酬。SNSシェア前提のスクショ映え。プレッシャーゼロ |
| **My Talking Tom** | 高品質アニメ、スキンシップへのコミカルな即時リアクション、着せ替え、ミニゲーム | **触った瞬間に必ず反応が返る**手触り。カスタマイズの物量 |
| **Pou** | シュールな見た目、シンプルな育成＋ミニゲーム、高い自由度 | キャラは「かわいい」より**愛嬌と個性**が刺さる |
| **Neopets** | プレイヤー間経済（ショップ・オークション）、ギルド、デイリー、株価 | 経済的動機と社会的アイデンティティ。ただし個人開発では重すぎる |
| **Webkinz** | フレンドの部屋訪問、トレード、部屋づくり、アーケードのスコアランキング | 「自分の部屋を見せたい」という**承認欲求の設計**。非同期でも十分成立する |
| **Character.ai / Talkie / Aidorable / Nuzzle 等 AIペット系** | LLMでペルソナ会話。1匹ずつ違う個性と記憶を持って成長 | 現在の最前線。ただし後述の弱点が未解決 |

2026年時点のトレンドは、従来の「ごはん・掃除」のお世話要素に加えて
**AIによる自然なコミュニケーション**と**メンタルヘルス／生活習慣サポート**が主戦場になっていること。

## 2. リテンションの4アプローチ（調査からの構造化）

| アプローチ | 具体的な機能 | なぜ戻ってくるか | 代表例 |
| --- | --- | --- | --- |
| ① 相互依存・ライフサイクル型 | 通信、結婚、アイテム交換、フレンド訪問 | 「相手を待たせている」「一緒に世代を進めたい」心理的義務感 | たまごっち、Webkinz |
| ② 経済・モチベーション型 | オークション、ショップ、トレード | 資産を増やしたい／レアを早く手に入れたい | Neopets |
| ③ 非同期・自己表現型 | 部屋カスタマイズ、コレクション公開、SNSシェア | こだわりを見せたい（承認欲求） | ねこあつめ、Webkinz |
| ④ 離脱防止（プレッシャー）型 | お世話要求、放置ペナルティ、サプライズ報酬 | 今開かないと損をする（FOMO）と期待感 | たまごっち、ねこあつめ |

要点: **単調なルーティンを、他者との関係性によってドラマに変える**こと。
プレッシャーの緩急（たまごっちの「死の恐怖」／ねこあつめの「いつ見ても癒やされる」）はどちらでも成立するが、
共通しているのは「次に開く明確な理由」を生活リズムに植え付けている点。

## 3. AIペット系アプリの弱点（＝我々の勝ち筋）

ストアレビュー・コミュニティで繰り返し挙がる不満:

1. **キャラクター崩壊（OOC）** — 会話が長引くと「何かお手伝いできることはありますか？」という汎用アシスタント口調に戻る。**世界中で最多の不満**
2. **長期記憶の破綻** — 大事な約束をピンポイントで忘れる／逆に間違った文脈で過去の記憶を持ち出す（記憶ハルシネーション）
3. **課金でのメッセージ制限**（スタミナ制）への不満
4. **仕様変更による「AIロス」** — 昨日まで親密だったAIが急に冷たい定型文を返す喪失感
5. **プライバシー不安** — 個人的な悩みや生活スケジュールをクラウドLLMに送ることへの抵抗

## 4. どう「いいとこ取り」するか

| 取り込む要素 | 出典 | 本作での実装 |
| --- | --- | --- |
| 触った瞬間の即時反応 | My Talking Tom | 撫でる／エサ／おもちゃは**LLMを待たずローカルで即アニメ＋定型リアクション**。裏で走ったLLMの一言が遅れて吹き出しに追加される（体感遅延ゼロ） |
| 非同期サプライズ | ねこあつめ | 再ログイン時に「留守中の出来事レポート」を必ず1件以上出す |
| 緩和されたケアトリガー | たまごっち | 空腹・退屈・清潔はゆっくり減衰。**死なない**が、放置すると気分が拗ねる方向へドリフトし会話のトーンが変わる（罰ではなく物語化） |
| 生活習慣連動 | Finch | 任意の「今日の約束」を1つ登録できる。達成報告するとペットが褒め、記憶に残す（強制しない軽量版） |
| 部屋づくり・訪問 | Webkinz | 家具を配置した部屋を公開し、フレンドが非同期訪問。訪問痕跡が残る |
| 収集と交換 | Neopets | アイテムのギフト送付のみ（経済シミュは作らない） |
| 個性と記憶で育つAI | Aidorable系 | 3層記憶＋性格ベクトルで**弱点1・2を正面から潰す** |

意図的に採用しないもの: メッセージ数のスタミナ制（弱点3）、プレイヤー間経済シミュレーション（個人開発では過剰）。

## 5. 他にない強み（本作の3本柱）

### ① 崩れない性格・忘れない記憶

- 性格を自由記述ではなく **8軸の数値ベクトル**（元気/甘えん坊/わがまま/賢さ/社交性/食いしん坊/臆病さ/いたずら）で保持し、
  毎リクエストで数値からプロンプトを機械生成する。会話履歴に引きずられて口調が漂流しない。
- 語尾・語彙・禁止表現（アシスタント語）を **speech profile** として固定注入し、出力を検証して違反時は1回だけリトライ。
- 記憶は3層構造。そして**何を覚えているかをユーザが「おもいで帳」で全部見られ、編集・削除できる**。
  「間違った記憶を持ち出す」問題をユーザ側から矯正できる設計は既存アプリにない。

### ② ペット同士のAI交流ドラマ

- オフライン中に他ユーザのペットとマッチングし、双方の性格ベクトルと記憶を入力に LLM が会話ログを生成。
- 相性・喧嘩・仲良しが自然に発生し、関係値が蓄積する。
- 翌日ログインすると自分のペットが**土産話**をしてくれ、その内容が記憶として定着する。
- 「非同期マルチユーザ」と「LLMの強み」が同じ機構で成立するのが本作の核心。

### ③ 自律行動する2Dステージ

- ペットは指示待ちではなく、ニーズ・性格・時刻から自分で行動を選んで画面上で動く。
- 行動は**ホワイトリスト化された action enum**なので、LLMが何を返しても画面が壊れない。
- 高頻度は決定論的FSM、低頻度でLLMが「思いつき」を差し込む（コストと安定性の両立）。
