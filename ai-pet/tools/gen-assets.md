# アセット生成の台帳（docs 08章）

生成に使ったプロンプトを残す台帳。**あとから1枚だけ足すときも絵柄がぶれない**ようにするため、
採用したプロンプトは必ずここへ追記する。

## 実行方法

```bash
# リポジトリのルート（games/）で実行する
UV_CACHE_DIR="$PWD/.uv_cache" uv run --with httpx --with python-dotenv --with openai --with pyyaml \
  python /Users/ryosato/.claude/skills/img-gen-gpt/scripts/generate_image.py \
  --operation generate \
  --prompt "<共通スタイル句> + <個別の指示>" \
  --output-dir "$PWD/ai-pet/.tmp/asset-gen/<一意な名前>" \
  --background transparent --output-format png --quality medium \
  --env-file /Users/ryosato/projects/private/english-learn/.env
```

前提（記録済みの制約）:

- このリポジトリの `.env` に `AZURE_OPENAI_US_*` は**無い**。`english-learn/.env` を渡す
- `gpt-image-1-mini` は `--input-fidelity high` を受け付けない
- **並列実行するときは `--output-dir` を1回ごとに分ける**（出力名がタイムスタンプなので衝突する）
- 1枚 medium/1024x1024 で約 $0.011、所要1〜2分

## 後処理

```bash
# 生成物を <種別>_<名前>_<方向>.png にリネームして1つのディレクトリに集めてから
UV_CACHE_DIR="$PWD/.uv_cache" uv run --with pillow \
  python ai-pet/tools/install-assets.py \
  --src ai-pet/.tmp/asset-raw --dst ai-pet/packages/client/public/assets/game
```

- 霞を落とし → 外接矩形で切り抜き → キャラ48px / タイル32px へ縮小 → 下端合わせ
- **`_w`（左向き）は `_e`（右向き）から自動で左右反転**して作られる。生成しなくてよい

## 共通スタイル句（すべてのプロンプトの先頭に置く）

```
かわいい2Dゲーム用の手描き風イラスト、太めの茶色の輪郭線（#4a3b2a）、
やわらかいパステル配色（草色 #d9ee94 / クリーム #fffdf3 / 紫 #a892e0 / 桃 #ffb9a3 / 空 #9fd8ee）、
平坦な塗り、影は1段のみ、斜め見下ろし（クォータービュー）視点、
背景は完全な透明、余白なし、単体オブジェクトのみ、テキストや文字は一切なし、影や地面は描かない
```

## キャラクターの方向

- `_s` = 正面（手前を向いてこちらを見る）
- `_n` = 背面（奥を向いて後ろ姿。顔は見えない）
- `_e` = 右向き（横向きの全身、右を向く）
- `_w` = 生成しない（`_e` の反転）

**同じキャラの3方向は「同じ体型・同じ色・同じ模様」であることが最優先。**
個別の指示に体型・色・特徴を必ず具体的に書く（「前の画像と同じ」は効かない）。

### 地形タイル（tile_*）

タイルは**共通スタイル句を使わない**。「単体オブジェクト」「透明背景」がタイルと矛盾するため、
下の**タイル専用スタイル句**に差し替える（`--background opaque` で実行する）。

```

やわらかいパステル配色、平坦な塗り、影は付けない。真上から見た地面の質感だけを描く。
極小のモチーフを全面に均等に散らすだけで、木・草むら・岩・道・水辺・建物・生き物などの
大きな物は絶対に描かない。風景や地図にしない。モチーフ1個の大きさは画面の30分の1以下にする。
上下左右の端は繰り返しても継ぎ目が出ないようにつなげる。全面を塗りつぶし、透明部分は作らない。
外周に枠線や縁取りを描かない。テキストや文字は一切なし。
```

上の「壁紙のリピートパターン」「モチーフは画面の30分の1以下」「風景や地図にしない」の
3点が効いた。個別指示も「ベースは○○の一色塗り。その上に△△だけを散らす。それ以外は

### ペット5種 × 3方向（2026-08-07 追記）

15枚すべて `<共通スタイル句> + <種の体の指示> + <方向の指示> + <NS> [+ <FIT>]` で作った。
`_w` は `install-assets.py` が `_e` を反転して作るので生成していない。

**追加した共通の禁止句（`NS`）** — これを入れないと足元に灰色の楕円の影が描かれる。
実際に hakka_s / hoshira_s / hakka_n / hoshira_n で影が出て作り直した。

```
地面の影や楕円形の影は絶対に描かない。キャラクター以外のものは何も描かない。背景は完全に透明。
```

**見切れ防止句（`FIT`）** — 横向き（`_e`）で耳や足が画面外に出たときに追加する。

```
キャラクターの全身が画面の中に完全に収まっていて、上下左右に少し余白がある。見切れさせない。
```

**方向の指示**

- `_s`: `正面を向いて立ち、こちらをまっすぐ見ている全身。`
- `_n`: `真後ろから見た後ろ姿の全身。顔はまったく見えないので目・鼻・口は描かない。頭の後ろと背中だけが見える。`
- `_e`: `真横から見た右向きの立ち姿の全身。完全な横顔（プロフィール）で、顔は画面の右を向き、目は右側の1つだけが見える。`
  （`_e` は「右向きの全身」だけでは3/4のあおり顔になる。**「完全な横顔」「目は1つだけ」を必ず書く**）

**種の体の指示**（3方向で同じ文をそのまま使い回すこと）

```

  ```

  **`あかるいうすい藤色（ラベンダー、RGB 215,199,242）`＋`暗い紫やグレーは使わない`** と数値で指定して揃えた。

### 動物住民6種＋プレイヤー × 3方向（2026-08-07 追記）

21枚すべて `<動物住民用スタイル句> + <種の体の指示> + <方向の指示> + <NS> + <FIT>` で作った。
`_w` は `install-assets.py` が `_e` を反転して作るので生成していない。
プロンプト部品は `ai-pet/.tmp/critters.sh` に、実行ラッパは `ai-pet/.tmp/gen-critter.sh` に置いてある。

**動物住民用スタイル句**（ペットの共通スタイル句からパステルの色指定を外し、
「自然でやや彩度を抑えた土や森の色」に差し替えたもの。これでペット5種とはっきり見分けがつく）

```
かわいい2Dゲーム用の手描き風イラスト、太めの茶色の輪郭線（#4a3b2a）、平坦な塗り、影は1段のみ、
斜め見下ろし（クォータービュー）視点、背景は完全な透明、余白なし、単体オブジェクトのみ、
テキストや文字は一切なし。色はパステルではなく、自然でやや彩度を抑えた落ち着いた土や森の色にする。
```

`NS`（影の禁止句）はペットと同じものをそのまま使った。**21枚すべて影は出なかった**
（ペットのときと違い1枚も影で作り直していない）。

`FIT` は次の文で全枚数に最初から入れた（`_e` の見切れ予防）。

```
キャラクター1体だけを描く。全身が画面の中に完全に収まっていて、上下左右に少し余白がある。見切れさせない。
```

いのししだけこれでも鼻先が見切れたので、次の**強い版 `FIT2`** に差し替えて解決した。

```
キャラクター1体を画面の中央に、やや小さめに描く。鼻先・しっぽ・足先を含めた全身が画面の内側に
完全に収まり、上下左右の四辺に画面の10分の1以上の余白がある。絶対に見切れさせない。
```

**方向の指示**（`_n` はペット版に「くちばし・ひげ」を足した。鳥とねこで顔の部品が残るのを防ぐため）

- `_s`: `正面を向いて立ち、こちらをまっすぐ見ている全身。`
- `_n`: `真後ろから見た後ろ姿の全身。顔はまったく見えないので目・鼻・口・くちばし・ひげは描かない。頭の後ろと背中とおしりだけが見える。`
- `_e`: `真横から見た右向きの立ち姿の全身。完全な横顔（プロフィール）で、顔は画面の右を向き、目は右側の1つだけが見える。`

### 手直し: 接地影の除去とタイルの彩度調整（2026-08-07 追記）

**画像生成は1回も行っていない。すべて Pillow の後処理で済ませた（コスト $0.00）。**
作業前の原寸は `ai-pet/.tmp/asset-backup/`（50枚）に退避してある。

#### 1. `obj_bridge` / `obj_well` の接地影を消した

上の「注意（未解決）」で「プロンプトでは取り切れない」としていた影を、後処理で解決した。
スクリプトは `ai-pet/.tmp/deshadow.py`。**再生成より確実で無料なので、以後この方法を使う。**

やり方は「影の中の1点を種にした連結領域の塗りつぶし（フラッドフィル）」。
影は本体の茶色い輪郭線の外側にある独立した塊なので、色の近い隣接画素だけを辿れば本体を削らない。
本体を守るための条件（`protect`）は2枚で違う:

| ファイル | 影の色 | 本体を守る条件 | 消した画素数 |
|---|---|---|---|
| `obj_bridge` | ラベンダー `rgb(191,180,197)` | `b < r - 12`（茶色は赤>青。橋は全部茶色） | 37,625 + 縁1,285 |
| `obj_well` | 無彩色グレー `rgb(216,213,208)` | `max-min > 14`（石はラベンダーで G が凹む＝色みがある） | 6,770 + 縁611 |

- 井戸は**石積み自体がラベンダー**なので、色相ではなく**彩度**で影と石を見分けるのが要点。
  「紫っぽい色を消す」だと井戸本体が溶ける。
- 塗りつぶしのあと **2px 分の縁（フリンジ）取り込み**が必要。影のアンチエイリアスが
  影の形の輪郭線として残る。
- さらに**本体から切り離された小さな島を捨てる処理**（`drop_islands`、最大成分の2%未満）を入れた。
  橋の影には薄い暗色の輪郭線が引かれていて、これが残ると `install-assets.py` の外接矩形が
  下へ40pxほど伸び、48px枠のなかで橋が上にずれてしまう。
- 井戸は台座の下に残った小さなグレーの塊（158px）に追加の種 `(570,930)` を打って消した。

結果: 48px でも 1024px でも影は完全に消え、`obj_bench` などと同じ「影なし」に揃った
（`ai-pet/.tmp/asset-check/objs_on_tiles_48.png`、`ai-pet/.tmp/asset-check-t/objs_ongrass.png` で確認）。

#### 2. `tile_grass` / `tile_forest` の彩度を下げた

スクリプトは `ai-pet/.tmp/desat-tiles.py`（`uv run --with pillow python ai-pet/.tmp/desat-tiles.py 0.78 0.78`）。
**HSV の S だけを 0.78 倍**し、H と V は触っていない。

| ファイル | S（前） | S（後） | V（不変） | 寄せた宣伝資料の色 |
|---|---|---|---|---|
| `tile_grass` | 0.485 | **0.378** | 0.921 | `#d9ee94`（S=0.378）と一致 |
| `tile_forest` | 0.674 | **0.526** | 0.639 | `#bfe06a`（S=0.527）と一致 |

- **V を変えないのが重要**。草地と森の見分けは彩度ではなく明度（0.921 vs 0.639）で付いているので、
  S だけ落としても境目は読める（`ai-pet/.tmp/asset-check/tiles_desat_compare.png` の32px×4×4で確認）。
- 参考の他タイル: sand S=0.304 / plaza S=0.224 / water S=0.460 / dirt S=0.687。
  草地 0.378 は sand と water の間に収まり、前に出て見えなくなった。
- `tile_dirt` も S=0.687 と高いが今回の指示の対象外なので触っていない。次に気になったらここも 0.78 倍でよい。

設置後のファイル数は 62枚（原寸50枚 + `_w` 反転12枚）で変化なし。
