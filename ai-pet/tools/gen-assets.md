# アセット生成の台帳（docs 08章）

生成に使ったプロンプトを残す台帳。**あとから1枚だけ足すときも絵柄がぶれない**ようにするため、
採用したプロンプトは必ずここへ追記する。

## 実行方法

```bash
# リポジトリのルート（games/）で実行する
UV_CACHE_DIR="$PWD/.uv_cache" uv run --with httpx --with python-dotenv --with openai --with pyyaml \
  python /Users/ryosato/.claude/skills/img-gen-gpt/scripts/generate_image.py \
  --operation generate \
  --prompt "<共通スタイル句> + <個別の指示>" \
  --output-dir "$PWD/ai-pet/.tmp/asset-gen/<一意な名前>" \
  --background transparent --output-format png --quality medium \
  --env-file /Users/ryosato/projects/private/english-learn/.env
```

前提（記録済みの制約）:

- このリポジトリの `.env` に `AZURE_OPENAI_US_*` は**無い**。`english-learn/.env` を渡す
- `gpt-image-1-mini` は `--input-fidelity high` を受け付けない
- **並列実行するときは `--output-dir` を1回ごとに分ける**（出力名がタイムスタンプなので衝突する）
- 1枚 medium/1024x1024 で約 $0.011、所要1〜2分

## 後処理

```bash
# 生成物を <種別>_<名前>_<方向>.png にリネームして1つのディレクトリに集めてから
UV_CACHE_DIR="$PWD/.uv_cache" uv run --with pillow \
  python ai-pet/tools/install-assets.py \
  --src ai-pet/.tmp/asset-raw --dst ai-pet/packages/client/public/assets/game
```

- 霞を落とし → 外接矩形で切り抜き → キャラ48px / タイル32px へ縮小 → 下端合わせ
- **`_w`（左向き）は `_e`（右向き）から自動で左右反転**して作られる。生成しなくてよい

## 共通スタイル句（すべてのプロンプトの先頭に置く）

```
かわいい2Dゲーム用の手描き風イラスト、太めの茶色の輪郭線（#4a3b2a）、
やわらかいパステル配色（草色 #d9ee94 / クリーム #fffdf3 / 紫 #a892e0 / 桃 #ffb9a3 / 空 #9fd8ee）、
平坦な塗り、影は1段のみ、斜め見下ろし（クォータービュー）視点、
背景は完全な透明、余白なし、単体オブジェクトのみ、テキストや文字は一切なし、影や地面は描かない
```

## キャラクターの方向

- `_s` = 正面（手前を向いてこちらを見る）
- `_n` = 背面（奥を向いて後ろ姿。顔は見えない）
- `_e` = 右向き（横向きの全身、右を向く）
- `_w` = 生成しない（`_e` の反転）

**同じキャラの3方向は「同じ体型・同じ色・同じ模様」であることが最優先。**
個別の指示に体型・色・特徴を必ず具体的に書く（「前の画像と同じ」は効かない）。

### 地形タイル（tile_*）

タイルは**共通スタイル句を使わない**。「単体オブジェクト」「透明背景」がタイルと矛盾するため、
下の**タイル専用スタイル句**に差し替える（`--background opaque` で実行する）。

```
かわいい2Dゲーム用の手描き風の、シームレスな繰り返し模様（壁紙のリピートパターン）。
やわらかいパステル配色、平坦な塗り、影は付けない。真上から見た地面の質感だけを描く。
極小のモチーフを全面に均等に散らすだけで、木・草むら・岩・道・水辺・建物・生き物などの
大きな物は絶対に描かない。風景や地図にしない。モチーフ1個の大きさは画面の30分の1以下にする。
上下左右の端は繰り返しても継ぎ目が出ないようにつなげる。全面を塗りつぶし、透明部分は作らない。
外周に枠線や縁取りを描かない。テキストや文字は一切なし。
```

書くだけだと、モデルは**木・道・砂浜・池を配置した俯瞰マップ**を描いてしまう。
上の「壁紙のリピートパターン」「モチーフは画面の30分の1以下」「風景や地図にしない」の
3点が効いた。個別指示も「ベースは○○の一色塗り。その上に△△だけを散らす。それ以外は
何も描かない」という形にすると安定する。

### ペット5種 × 3方向（2026-08-07 追記）

15枚すべて `<共通スタイル句> + <種の体の指示> + <方向の指示> + <NS> [+ <FIT>]` で作った。
`_w` は `install-assets.py` が `_e` を反転して作るので生成していない。

**追加した共通の禁止句（`NS`）** — これを入れないと足元に灰色の楕円の影が描かれる。
実際に hakka_s / hoshira_s / hakka_n / hoshira_n で影が出て作り直した。

```
地面の影や楕円形の影は絶対に描かない。キャラクター以外のものは何も描かない。背景は完全に透明。
```

**見切れ防止句（`FIT`）** — 横向き（`_e`）で耳や足が画面外に出たときに追加する。

```
キャラクターの全身が画面の中に完全に収まっていて、上下左右に少し余白がある。見切れさせない。
```

**方向の指示**

- `_s`: `正面を向いて立ち、こちらをまっすぐ見ている全身。`
- `_n`: `真後ろから見た後ろ姿の全身。顔はまったく見えないので目・鼻・口は描かない。頭の後ろと背中だけが見える。`
- `_e`: `真横から見た右向きの立ち姿の全身。完全な横顔（プロフィール）で、顔は画面の右を向き、目は右側の1つだけが見える。`
  （`_e` は「右向きの全身」だけでは3/4のあおり顔になる。**「完全な横顔」「目は1つだけ」を必ず書く**）

**種の体の指示**（3方向で同じ文をそのまま使い回すこと）

```
mofi:
ふわふわした白い雲のような小動物のキャラクター1体。二頭身のちび体型、頭と体がつながった丸くもこもこした輪郭、
クリーム色 #fffdf3 の体、頭のてっぺんに丸い耳が2つ（耳の内側は薄いピンク #ffc9be）、
頬に薄い桃色 #ffb9a3 の丸、とても短く小さな足。

mizune:
うすい水色 #9fd8ee の子ねこのキャラクター1体。二頭身のちび体型、丸くて大きな頭、三角にとがった猫耳が2つ、
細く切れ長の目でクールで無表情、体の後ろに長い水色のしっぽがゆるくカーブしている、
とても短く小さな足、おなかはクリーム色 #fffdf3。

hakka:
うすい緑 #a8e0b4 のうさぎのキャラクター1体。頭が大きく体が小さい二頭身のちび体型、丸くて大きな頭、
上にまっすぐ長く伸びた大きな耳が2つ（耳の内側は薄いクリーム色 #fffdf3）、
黒い点の丸い目でまじめでやさしい笑顔、小さな丸いしっぽ、とても短く小さな足、二本足で直立している。

momona:
桃色 #ffb9a3 の丸い子いぬのような小動物のキャラクター1体。頭が大きく体が小さい二頭身のちび体型、丸くて大きな頭、
頭の両側に大きく垂れ下がった長い垂れ耳、黒い点の目、口を大きく開けた元気いっぱいの笑顔、
とても短く小さな足、二本足でまっすぐ直立している（四つ足にはしない）。

hoshira:
うすい紫 #a892e0 のちょうのような小さな生きもののキャラクター1体。頭が大きく体が小さい二頭身のちび体型、
丸くて大きな頭と丸い体、背中の左右に小さな丸い羽が2枚（羽は頭よりずっと小さい）、
細い半目で夢見がちなねむそうな表情、額の中心に小さな黄色い星のしるし、とても短く小さな足。
```

**方向ごとの上書きが必要なもの**

- `pet_momona_e`: `二本足でまっすぐ直立している（四つ足にはしない）` が無いと四つ足の子犬になる
- `pet_hoshira_n`: 額の星を背中に描いてしまい、羽もクリーム色に変わるので、次のように上書きした
  ```
  背中の左右に小さな羽が2枚（羽の色も体と同じ）、額の星のしるしは後ろからは見えないので星も描かない。
  ```
  さらに `#a892e0` と書くと `_s`/`_e` より暗い紫（RGB 192,170,200）になったため、
  **`あかるいうすい藤色（ラベンダー、RGB 215,199,242）`＋`暗い紫やグレーは使わない`** と数値で指定して揃えた。
