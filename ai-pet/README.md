# おもいでペット（ai-pet）

ブラウザで動く 2D・マルチユーザの AI ペット育成ゲーム。
ペットは Azure OpenAI（`gpt-5.6-luna`）でペルソナ化されていて、飼い主のことを覚え、
自分で動き、留守のあいだに他のユーザのペットと出会って話してくる。

調査結果と設計判断は [`01_research.md`](01_research.md) に詳しい。

## この作品の3本柱

### 1. 崩れない性格・忘れない記憶

既存の AI ペットアプリで最も多い不満は「会話が長引くと汎用アシスタント口調に戻る（キャラクター崩壊）」と
「長期記憶の破綻」だった。本作はこれを構造で潰している。

- **性格は 8 軸の数値ベクトル**（元気/甘えん坊/わがまま/賢さ/社交性/食いしん坊/臆病さ/いたずら）。
  毎リクエストで数値から説明文を機械生成して注入するので、履歴が伸びても性格の記述量が薄まらない
  （`shared/personality.ts`）。
- **出力側で崩壊を検出**する。助手口調・メタ発言・箇条書きを検出したら1回だけ言い直させ、
  それでも直らなければ定型に落として、ユーザには崩壊を見せない（`server/llm/speechGuard.ts`）。
- **記憶は3層**（`server/pet/memory.ts`）。
  1. 事実層 — `owner_name` などのホワイトリストされたキーと値。キーで上書きされるので矛盾しない。常に全件注入
  2. エピソード層 — 出来事の要約。`重要度 × 新しさ × 参照実績 + 語の一致` のスコア上位のみ注入。
     ベクトルDBを使わない決定論的な実装なのでテストできる
  3. 直近会話層 — 最新 12 ターン
- **おもいで帳**で、覚えていることを全部ユーザが見て、直して、消せる。
  AI が間違って覚えた記憶をユーザ側から矯正できる点が既存アプリにない。

### 2. ペット同士のAI交流ドラマ

自分がオフラインの間に、ペットが他のユーザのペットと出会って会話する（`server/pet/encounter.ts`）。
双方の性格ベクトルと記憶を入力にするので、相性・喧嘩・仲良しが自然に発生し、関係値が蓄積する。
生成した会話は双方のエピソード記憶に書き戻され、次にログインすると**土産話**として語られる。

「非同期マルチユーザ」と「LLM の強み」が同じ機構で成立するのが本作の核心。

### 3. 広いマップを自律的に歩き回る2Dステージ

ペットは指示待ちではない。**画面の 4.6 倍の広さ**のマップを、自分で行き先を決めて歩き回る。

以前は1部屋しかなく、行動の種類を増やしても「同じ床で別のポーズを取る」だけで
見ていて面白くならなかった。そこで世界を6ゾーンに広げ、各ゾーンに**興味スポット**（全21箇所）を置いた
（`shared/world.ts`）。行動が場所と結びつくので、画面を見ているだけで物語が読める。

| ゾーン | 主なスポットと、そこでする行動 |
| --- | --- |
| ねむりべや | ベッド（寝る・ごろごろ）、クッション（空想）、よるのランプ（夜だけ） |
| だいどころ | ごはんのおさら（食べる）、れいぞうこ（物色）、おかしのたな（隠す・埋める） |
| リビング | おもちゃばこ（遊ぶ）、まるまど（外を眺める）、ラグ（片付け・踊る）、げんかん（待つ・拗ねる） |
| みずば | たらい（体を洗う・水はね）、かがみ（踊る・伸びをする） |
| にわ | はなだん（においをかぐ）、つち（掘る・埋める）、みずたまり（跳ねる）、ちょうちょ（追いかける／昼だけ）、ポスト（覗く） |
| おかのうえ | おおきな木（のぼる）、ベンチ（ひなたぼっこ／昼だけ）、ことりのす（話す）、ほし見のおか（星を眺める／夜だけ） |

行き先の決め方（`src/sim/agenda.ts`）:

1. **スポットを重み付き抽選**する。ニーズの不足 × 性格 × 時刻（昼夜）× 目新しさ × 距離
2. そこまで歩く。屋外は臆病な子ほど行きたがらず、元気な子ほど遠出する
3. 着いたらそのスポットの行動をする。ときどき**発見**が起きる（「つちを ほったら、ひかる石を 見つけた」）
4. 1 に戻る

- 見た目の動きは**決定論的**で毎フレーム回す。LLM を待たない
- 発見は**記憶（エピソード層）に書き戻される**ので、あとの会話で本人が持ち出してくる。
  文章は `shared/world.ts` の定義から**サーバ側で引く**ので、クライアントの文字列がプロンプトや記憶に入ることはない
- 90 秒に1回だけ LLM に「思いつき」を聞く。このとき**いまいる場所を渡す**ので、独り言がその場所の話になる
- 行動は**ホワイトリスト化された enum**（`shared/actions.ts`、全28種）なので、LLM が何を返しても画面は壊れない
- 留守レポートも同じ式（`spotAppeal`）で「留守中どこにいたか」を語るので、
  見ているときの行き先と食い違わない

見失わないための工夫:

- カメラがペットを追いかける。**横ドラッグで自分で見て回れる**（6秒後にまた追尾に戻る）
- 画面下の帯に**ゾーンの並びと現在位置**、「ころは にわの みずたまり」と現在地を常に出す
- HUD に**できごとログ**を3行だけ流す（部屋を移ったとき・発見したときだけ書くので流れすぎない）
- 発見には 🪙3 のごほうび。放置で無限に稼げないよう **5分に1回・1日24枚まで**（サーバ側で制限）

### おまけ: 性格がミニゲームのむずかしさを変える

「どこに かくした？」（`shared/minigame.ts`）は、3つの箱のどれにおやつを隠したか当てるゲーム。
性格ベクトルがそのまま難易度になるので、「この子だから難しい／簡単」が体験できる。

| 性格 | ゲームでの現れ方 |
| --- | --- |
| 賢さ が高い | 箱を多くシャッフルして目で追いにくくする |
| いたずら が高い | シャッフル後にこっそり中身を入れ替える（フェイント） |
| 臆病さ・甘えん坊 が高い | 隠した箱を つい見てしまい、ヒントが出る |

## 動かす

```bash
npm install
npm run dev          # サーバ(8787) と Vite(5273) を同時に起動
# http://localhost:5273/
```

リポジトリ直下の `.env` から Azure OpenAI の接続情報を読む（`server/env.ts`）。
**API キーはサーバプロセスだけが読み、ブラウザには一切渡らない。**

| 環境変数 | 用途 |
| --- | --- |
| `AZURE_OPENAI_ENDPOINT` / `AZURE_OPENAI_API_KEY` / `AZURE_OPENAI_API_VERSION` | Azure OpenAI 接続 |
| `LLM_MODEL_PET` | デプロイ名（既定 `gpt-5.6-luna`） |
| `AI_PET_DB` | SQLite の保存先（既定 `data/ai-pet.sqlite`） |
| `AI_PET_PORT` | API サーバのポート（既定 `8787`） |
| `AI_PET_THINK_INTERVAL_MS` | 自律思考の最短間隔（既定 90 秒） |
| `AI_PET_ENCOUNTER_INTERVAL_MS` | ペット同士の交流の最短間隔（既定 3 時間） |

接続情報が無い場合も**遊べる**。LLM が使えないときは定型リアクションにフォールバックする。

```bash
npm run typecheck    # クライアントとサーバの両方
npm test             # vitest（177件）
npm run build
```

## LLM の呼び出し回数（コストの目安）

| 操作 | 呼び出し |
| --- | --- |
| 世話（なでる・ごはん・あそぶ・おてあて）1回 | 1〜2回（崩壊検出でリトライした場合 2回） |
| 会話1往復 | 1〜2回 |
| 久しぶりに開いたときの第一声 | 1〜2回 |
| 自律思考 | 90 秒に最大1回（いまいる場所を一緒に渡す） |
| 自律行動・発見 | 0回（LLM を使わない） |
| ペット同士の交流1回 | 1回（やや大きめ、最大 1200 トークン） |
| ミニゲーム | 0回（LLM を使わない） |

世話は**押した瞬間に定型リアクションを出し**、LLM の一言は返ってきたら差し替える設計なので、
呼び出しが遅くても体感は待たされない（My Talking Tom の手触りを参考にした）。

同じ理由で、**画面を開く処理は LLM を待たない**。ペット同士の交流はサーバ側で裏で走らせ、
できあがったら土産話として拾う（以前ここで待っていて、起動に20秒かかっていた）。

## 構成

```
shared/       クライアント・サーバ共有（型・性格・行動・アイテム・定型リアクション・ミニゲーム・ワールド）
src/          クライアント（Vite + 素のTS + Canvas2D、フレームワークなし）
  render/     ステージ描画（PNG があれば使い、無ければ手続き描画にフォールバック）
  sim/        自律行動のアジェンダ（agenda）、してほしいこと（wish）、成長ゲージ
  ui/         DOM の各パネル（会話・ミニゲーム・おもいで帳・おへや・ともだち・おみせ）
server/       Express + better-sqlite3（tsx で実行）
  llm/        Azure OpenAI 呼び出し / プロンプト生成 / 応答検証 / 崩壊検出
  pet/        ニーズ・成長・記憶・頭(brain)・交流・留守レポート・成長イベント
public/assets/ img-gen-gpt で生成した透過PNG
10_assets_plan/ アセット生成の台帳（gen.sh / install.py）
tests/        vitest
```

## アセットの再生成

プロンプトはすべて `10_assets_plan/gen.sh` に置いてあり、絵柄を揃えたまま再生成できる。

```bash
bash 10_assets_plan/gen.sh mocha_child_idle      # .tmp/assets/ に出る
uv run --with pillow python 10_assets_plan/install.py   # 整えて public/assets/ へ
```

画像生成には `AZURE_OPENAI_US_*` を持つ `.env` が必要（`AI_PET_IMG_ENV` で差し替え可能）。
`install.py` は、生成画像に残る薄い霞を除いて切り抜き、Web 用に縮小する。

## 遊び方

1. なまえとあいことばで登録し、3種の中から1匹むかえる（性格は種族バイアス込みで1匹ずつ違う）
2. たまごは話せない。**3回世話をして数分待つ**と孵化してお祝いが出る（コインももらえる）
3. 画面上の「してほしいこと」がいまの要求。対応するアイテムのボタンが光る
   （ペットは勝手に歩き回るので、**ステージを横にドラッグ**すると家の中や にわ・おかのうえ を見て回れる）
4. 名前や好きなものを話すと覚える。「おもいで」で何を覚えたか確認・修正できる
5. 「あそぶ」でミニゲーム。コインとごきげんが稼げる（この子の性格でむずかしさが変わる）
6. 「ともだち」でほかの人を探し、おへやを見に行ったり、おくりものを送ったりする
7. 「でかけた話」でペット同士の交流ログと土産話を読む
8. 「やくそく」に今日の目標を1つ書いて守ると、ペットが覚えてくれる（コインもたまる）
9. しばらく空けてから開くと、この子が**第一声で迎えてくれる**（覚えていることに触れてくる）

## プレイテストで直したこと

実際に playwright でブラウザを操作して遊び、見つけた問題を直した記録。

| 見つけた問題 | 直し方 |
| --- | --- |
| 次に何をすればいいか分からず手が止まる | 「してほしいこと」を常に1行表示し、対応するボタンを光らせる |
| ニーズのバーが何のバーか分からない | アイコンだけでなくラベルを添えた |
| 孵化が「チップの文字が変わるだけ」で通り過ぎる | お祝い画面＋紙吹雪＋コイン。通信が切れても見るまで出続ける |
| 画面を開くのに20秒かかる | ペット同士の交流を待たず、裏で走らせて後から拾う（52ms になった） |
| ミニゲームが目で追えず運ゲーだった | 隠す瞬間を見せ、入れ替わる箱が実際に位置を交換するアニメーションにした |
| 光らせるボタンが跳ねて押しにくい | 位置ではなく光だけを脈打たせる |
| 1日放置で全ニーズが 0 になり挽回不能に見える | 減衰を約半分にし、下限を設けた（罰にしない方針） |
| 留守レポートが「寝ている」と現在形で不自然 | 過去形にし、ニーズに応じた一文を足して物語にした |
| 帰ってきてもこの子自身が何も言わない | 記憶に触れる第一声を追加 |
| 模様替え中に肝心のステージが隠れる | 背後が見える高さのモーダルにした |
| 家具が壁に張り付いて浮いて見える | 床の帯の中に置き、ペットに対して十分な大きさにした |
| 吹き出しの行頭に「、」が落ちる | 禁則処理を入れた |
| ペットが部屋の外まで歩いて切れる | 体の幅ぶん内側で止めるようにした |
| ミニゲーム中に勝手に寝てしまう | パネルを開いている間は行動を切り替えない |
| 1部屋しかなく、行動が増えても単純でつまらない | 世界を6ゾーン・21スポットに広げ、行き先を自分で選んで歩くようにした |
| 広くするとペットを見失う | カメラ追尾＋現在地の帯＋できごとログ。横ドラッグで自分でも見て回れる |
| みずばの鏡が空中に浮いて見える | 床まで届く支柱と台を足した |
| 端のゾーンの名前札が画面外にはみ出す | 札を「そのゾーンの見えている範囲」の中央に寄せた |

## 設計上の割り切り

- 認証は個人利用レベル（scrypt + セッションCookie）。公開運用するならレート制限などの強化が必要
- ペットは死なない。放置すると `mood` が下がり会話のトーンが拗ねる方向へ変わる（罰ではなく物語化）
- ミニゲームの進行はサーバのメモリに持つので、サーバ再起動で中断中のゲームは消える
- フレンドは申請・承認なしで相互になる（非同期ソーシャルの摩擦を減らすため）
- ペット同士の交流は LLM 1コールに数秒かかるので、ログイン時に走らせて結果を留守レポートで見せる
