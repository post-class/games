# 06. クライアント設計

## 1. 構成

- **Pixi（Canvas/WebGL）**：島・アクター・エフェクト。ゲーム世界のすべて。
- **DOM（通常のHTML/CSS）**：チャット欄、ペット設定、留守中サマリ、設定、ミニマップ枠。
  → 日本語の入力・折返し・アクセシビリティはDOMの方が圧倒的に楽なので、UIはPixiに描かない。
  宣伝資料の丸ゴシック＋太い輪郭のトーンはCSSで再現する（`01_ゲーム宣伝用資料/index.html` の配色変数を流用）。

```
main.ts
 ├─ net/socket.ts     WS接続・再接続・補間バッファ
 ├─ state/world.ts    受信状態の保持（Map<EntityId, ActorView>）
 ├─ render/
 │   ├─ stage.ts      Pixi Application、レイヤ構築
 │   ├─ tilemap.ts    チャンク単位の地形描画
 │   ├─ sprites.ts    アクター描画・アニメ・深度ソート
 │   ├─ camera.ts     追従・ズーム・境界クランプ
 │   ├─ effects.ts    吹き出し・天気・時間帯の色被せ
 │   └─ minimap.ts
 ├─ ui/               DOM（Vanilla TS + テンプレート関数）
 └─ input.ts          キー・ポインタ・タッチ
```

UIフレームワークは入れません（Reactを足すほどの画面数がない）。
`ui/` は「状態を受けてinnerHTMLを組む関数＋イベント委譲」で十分です。

## 2. レイヤ構造（Pixi Container）

```
stage
 └ worldRoot            (camera変換をここに適用)
    ├ layerGround       地形タイル（チャンクごとにRenderTextureへ焼く）
    ├ layerDecalShadow  影・水たまり（乗算）
    ├ layerObjects      木・設置物・資源  ┐
    ├ layerActors       動物・ペット・人  ├ この3層は1つのContainerに統合し
    ├ layerOverObj      手前の木の枝など  ┘ y座標でzIndexソート
    ├ layerBubbles      吹き出し（常に手前）
    └ layerWeather      雨・霧パーティクル
 └ overlayRoot           (カメラ非依存)
    └ tint               時間帯の色被せ（朝=暖色/夜=紺、alphaで補間）
```

### 描画の要点

- **地形はチャンクごとにRenderTextureへ一度焼く**。128×128タイル＝16384スプライトを毎フレーム描くのは無駄。
  荒廃度が変わったチャンクだけ再焼成（1島時間に1回程度）。
- **深度ソート**：`sprite.zIndex = Math.round(y * 100)` として `sortableChildren = true`。
  クォータービュー風の絵柄でも、y順ソートだけで前後関係は成立する。
- **アニメーション**：1キャラ = 4方向 × (idle 2コマ / walk 4コマ / act 2コマ / sleep 2コマ)。
  `AnimatedSprite` ＋ スプライトシート（`08_アセット制作パイプライン.md`）。
- **視界外はculling**：`layerActors` の子はカメラ矩形外で `renderable = false`。
- スマホは `resolution = min(devicePixelRatio, 2)`、天気パーティクル数を1/3に。

## 3. カメラ

- 自キャラ追従。デッドゾーン（画面中央の1/6矩形）内は動かさない → 揺れが少ない
- ズーム 3段（0.75 / 1.0 / 1.5）。ピンチとホイールに対応
- 島の端でクランプ。島全体が画面より小さいときは中央寄せ
- 自ペットが画面外にいる間は、画面端に方向を示す小さな足跡アイコンを出す

## 4. 入力

| 操作 | PC | スマホ |
|---|---|---|
| 移動 | WASD/矢印 or 地面クリック | 地面タップ or 左下バーチャルパッド |
| 対象選択 | 対象クリック（ホバーで輪郭発光） | タップ（当たり判定を1.5倍に拡大） |
| 会話 | Enterでチャット欄フォーカス | 吹き出しボタン |
| ズーム | ホイール | ピンチ |
| ペット呼び出し | `Space` | 足跡ボタン長押し |

タップ判定は「アクター → 資源 → 設置物 → 地面」の優先順で拾い、
対象が取れたらコンテキストメニュー（撫でる／収穫／水やり／話す）を対象の上に出す。

## 5. UI画面一覧

| 画面 | 出るタイミング | 内容 |
|---|---|---|
| タマゴ選択 | ペット未作成時 | 5種のカード（`images/pets.png` の絵柄を流用）。名前・性格タグ3つ・口ぐせ・好物・苦手を入力 |
| 留守中サマリ | 接続直後（経過が10島分以上のとき） | 「島で3日経ちました」＋ペットの日記から3〜5行 |
| チャット | 常時（折りたたみ可） | 発話ログとテキスト入力。ペットの応答はストリーミング表示 |
| ペット情報 | ペットをクリック | 懐き度メーター、今の目標（`intent.reason`）、最近の記憶3件 |
| 島情報 | 上部バー常時 | 島日・季節・時間帯・天気・接続人数 |
| ミニマップ | 右下常時（折りたたみ可） | 地形の縮小＋自分/ペット/他プレイヤーの点 |
| 設定 | 歯車 | 音量、パーティクル量、表示名変更、アクセシビリティ |

## 6. 吹き出し

- Pixiの `Text` ＋ 9スライスの角丸背景（宣伝資料と同じ太い輪郭）。
- 長い応答は**ストリーミングで1文字ずつ追加**し、幅は最大14文字で折返して伸縮させる。
- 同時に多数出るとうるさいので、**画面内の吹き出しは最大5個**。溢れたら古いものを消す。
- プレイヤーとの会話はチャット欄にも全文残る（吹き出しは要約なしの先頭2行のみ）。

## 7. パフォーマンス目標と対策

| 症状 | 対策 |
|---|---|
| スプライト数が多い | 地形の焼成、culling、`ParticleContainer` を天気に使用 |
| GCスパイク | 毎フレームのオブジェクト生成を避ける（Vec2をプールし、deltaはin-place適用） |
| テクスチャ切替 | アトラス1〜3枚に収める（キャラ／地形／UI） |
| スマホの熱 | 非アクティブタブは `ticker.stop()`、復帰時にsnapshot再取得 |

計測は `stats` パネル（開発時のみ、`?debug=1`）で fps / drawCalls / entity数 / RTT を表示します。

## 8. アクセシビリティ・その他配慮

- 色だけに依存しない（懐き度はメーター＋数値、天気はアイコン＋文字）
- `prefers-reduced-motion` でパーティクルと画面揺れを無効化
- チャット欄はキーボードのみで完結（Tab順を明示）
- 文字サイズは3段階切替
- 音は既定OFF、初回操作後に有効化（自動再生ブロック対策）
