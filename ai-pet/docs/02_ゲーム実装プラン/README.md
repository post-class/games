## 3行サマリ

- **サーバ権威**の常駐Nodeプロセスが島の時間を進め続ける。動物住民は安価な**ユーティリティAI**（LLM不使用）で自律生活する。
- **AIペットだけがLLM**（Azure OpenAI / `gpt-5.6-luna`）を使う。「行動の決定」「会話」「1日の日記による記憶圧縮」の3用途に限定し、レート制限とフォールバックでコストと安定性を担保する。
- クライアントは **Vite + TypeScript + PixiJS v8** の薄い表示層。APIキーは絶対にクライアントへ出さない。

## 最初の一歩

`09_マイルストーン計画.md` の **M0 → M1** から着手します。
M1（島が描画され、1人で歩ける）が終われば、以降は毎マイルストーンで「遊べる状態」を保ったまま拡張していけます。
