# 01. 要件とスコープ

## 1. ゲームの本質（ここを外したら失敗）

宣伝資料の主張は「**住民が本当に自律している**」ことに全部を賭けている、というものでした。
実装上の優先順位もそれに従います。

1. **島が自分で回る** — プレイヤーが見ていなくても、動物が食べ、寝て、増える
2. **ペットが自分で考える** — 台本ではなくLLMが行動と発話を決める
3. **やらなくてもいい** — 強制クエスト・スタミナ待ちを実装しない
4. **みんなの島** — 同じ島に複数プレイヤーが同時にいる

「見栄えの良い箱庭」よりも「1週間放置して覗いたら島が変わっている」を先に成立させます。

## 2. 機能要件

### 2.1 島（世界）

| 要件 | 内容 |
|---|---|
| マップ | 128×128タイル（1タイル=32px相当）の島1枚。草地・土・砂・水・林・広場 |
| 時間 | 島の1日 = 実時間60分（朝/昼/夕/夜 各15分）。季節は7島日で1季、4季で1年 |
| 天気 | 晴れ/曇り/雨/霧。季節ごとの確率テーブルで島日単位に抽選、日中に変化もあり |
| 資源 | 木の実の木・畑・釣り場・水場。収穫されると枯渇し、時間で回復する |
| 環境の記憶 | タイルごとに「荒廃度」を持ち、踏み荒らし/収穫で上昇、時間で減衰 |
| オフライン進行 | サーバは常駐して進行。サーバ停止中の空白は再起動時に圧縮シミュレーションで埋める（上限24島時間） |

### 2.2 動物住民（NPC）

| 要件 | 内容 |
|---|---|
| 個体数 | 島あたり 60〜120体（上限は負荷に応じて調整） |
| 種類 | 6種（うさぎ／ねこ／とり／かえる／りす／いのしし系）×性格パラメータ |
| 欲求 | 空腹・眠気・社交・安全・好奇心の5軸 |
| 行動 | ユーティリティAIで毎tick評価し、最良の行動を選ぶ（採食・水飲み・就寝・移動・交流・逃走・巣づくり） |
| 関係性 | 個体間の好感度（-100〜+100）。友達／苦手が生まれ、群れの構成が変わる |
| 世代 | 年齢（島日）を持ち、成体同士の好感度が高いと繁殖。性格は親の平均＋ノイズで遺伝。寿命で退場 |
| LLM | **使わない**（コストと負荷のため。噂の文面など一部テキストのみ後述の例外あり） |

### 2.3 AIペット（プレイヤー1人1匹）

| 要件 | 内容 |
|---|---|
| 選択 | 5種（モフィ／ミズネ／ハッカ／モモナ／ホシラ）から1匹。名前・性格タグ・口ぐせ・好物・苦手を初期設定 |
| 会話 | プレイヤーの発話にLLMで応答。ペルソナ・記憶・現在の島の状況を踏まえる |
| 自律行動 | 90秒ごと（不在時は10分ごと）にLLMが「次の目標」を選択。移動やアクションはサーバの行動系が実行 |
| 記憶 | 短期リングバッファ＋エピソード記憶（重要度/新しさ/一致度で検索）＋島日ごとの日記要約 |
| 懐き度 | 会話・世話・放置で変動し、口調と距離感（追従距離）に反映 |
| 他個体交流 | 動物住民および他プレイヤーのペットと交流。ペット同士は短い会話を生成し、内容を互いの記憶に残す（噂） |
| 安全 | ペットの出力はホワイトリスト化されたenum行動のみ実行可能。プロンプトインジェクションでサーバ操作は不可能 |

### 2.4 マルチユーザー

| 要件 | 内容 |
|---|---|
| 同時接続 | 1島インスタンスあたり最大16プレイヤー。超過分は新インスタンス（シャード）へ |
| 認証 | MVPは匿名（クライアント生成のシークレット＋サーバ発行playerId）。将来メールリンク認証 |
| 同期 | サーバ権威。クライアントは入力送信と描画のみ。位置は補間表示 |
| 共同作業 | 橋づくりなど、複数人の貢献値を溜めて完成する建設物（M7） |

### 2.5 プレイヤー操作

- 移動（クリック/タップ移動 ＋ WASD/矢印）
- 対象へのインタラクト（水やり・収穫・撫でる・話しかける）
- ペットとのチャット（テキスト入力）
- 設置（ベンチ・花壇などの簡易クラフト）
- ログイン時の「留守中サマリ」表示

## 3. 非機能要件

| 項目 | 目標 |
|---|---|
| 動作環境 | Chrome / Safari / Firefox 最新2バージョン。PC＋スマホ（縦横両対応） |
| 初回ロード | 3G相当で10秒以内、アセット合計 5MB 以内（初期バンドル 2MB 以内） |
| 描画 | PC 60fps / スマホ 30fps 以上（画面内エンティティ150体時） |
| サーバtick | シミュレーション 4Hz、ブロードキャスト 4Hz、1tickの処理 40ms以内 |
| LLMレイテンシ | 会話の初トークンまで2秒以内（ストリーミング）。タイムアウト8秒でフォールバック |
| LLMコスト | 1プレイヤー1時間あたり 40 リクエスト以内（後述のレート制限で強制） |
| 秘密情報 | APIキーはサーバのみ。クライアントバンドルに `AZURE_*` を一切含めない |

## 4. スコープ外（今回作らない）

- 課金・ガチャ・ランキング
- ボイスチャット、リアルタイム音声（BGM/SEは入れる）
- 3D、動的ライティング
- スマホネイティブアプリ化
- ペット以外（動物住民）の全個体LLM化
- 対戦・PvP要素
- 本格的な不正対策（サーバ権威で十分な範囲まで）

## 5. MVP（M4完了時点）の定義

以下がすべて満たされたら「コンセプトが成立している」と判定します。

- [ ] ブラウザでURLを開くと島が表示され、自分のキャラクターが歩ける
- [ ] 2つのブラウザから同じ島に入り、互いの動きが見える
- [ ] 動物が60体以上、指示なしで採食・就寝・交流をしている
- [ ] タマゴから選んだペットが自分についてきて、話しかけると**ペルソナに沿った生成応答**が返る
- [ ] ブラウザを閉じて30分後に開くと、島の時間が進んでおり、留守中サマリが出る
