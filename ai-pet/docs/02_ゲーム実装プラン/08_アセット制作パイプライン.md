# 08. アセット制作パイプライン

## 1. 方針

- **img-gen-gpt スキル**（透過PNG可）で全アセットを生成する。
- 宣伝資料の絵柄（`docs/01_ゲーム宣伝用資料/images/*.png`）を**基準トーン**として固定し、
  すべての生成プロンプトに同じスタイル句を入れて一貫性を保つ。
- 生成 → 目視確認 → 不採用ならプロンプト修正して再生成、を繰り返す。
  採用したプロンプトは `tools/gen-assets.md` に**台帳として残す**（後から差分追加するときに絵柄がぶれないため）。

## 2. 共通スタイル句（全プロンプトに含める）

```
かわいい2Dゲーム用の手描き風イラスト、太めの茶色の輪郭線（#4a3b2a）、
やわらかいパステル配色（草色 #d9ee94 / クリーム #fffdf3 / 紫 #a892e0 / 桃 #ffb9a3 / 空 #9fd8ee）、
平坦な塗り、影は1段のみ、アンチエイリアスは弱め、
背景は完全な透明、余白なし、単体オブジェクトのみ、テキストなし、
斜め見下ろし（クォータービュー）視点
```

## 3. 必要アセット一覧

### 3.1 キャラクター（最優先）

| 種別 | 内容 | 枚数 |
|---|---|---|
| ペット5種 | モフィ／ミズネ／ハッカ／モモナ／ホシラ × 4方向 × (idle2 / walk4 / act2 / sleep2) | 5 × 4 × 10 = **200** |
| 動物6種 | うさぎ／ねこ／とり／かえる／りす／いのしし × 4方向 × (idle2 / walk4 / sleep2) | 6 × 4 × 8 = **192** |
| 子個体 | 動物6種の縮小版（生成せず0.7倍スケールで代用） | 0 |
| プレイヤー | 汎用アバター2種 × 4方向 × (idle2 / walk4 / act2) | 2 × 4 × 8 = **64** |

400枚以上を1枚ずつ生成するのは非現実的なので、**生成は「ポーズシート」単位**にします。

> 生成単位: 1キャラ1方向あたり「idle / walk×4 / act / sleep を横一列に並べたシート」を1枚生成
> → 1キャラ4枚 × 13キャラ = **52回の生成**

生成後に `tools/pack-assets.ts` で等間隔スライス → 個別フレーム化 → アトラス化します。
（AIは等間隔配置が苦手なため、スライス位置の自動検出＋手動補正のUIを `?tool=slice` に用意する。
 それでも破綻する場合は 1方向1ポーズずつ生成する運用に落とす。）

### 3.2 地形タイル

| 種別 | 内容 |
|---|---|
| 基本タイル | grass / dirt / sand / water / forest床 / plaza石畳 各3バリエーション = 18 |
| 遷移タイル | 草⇄土、砂⇄水 の縁（4方向＋角）= 16 |
| 荒廃バリエーション | grass / dirt の荒れた版 = 4 |

タイルは**シームレスである必要がある**ため、生成物をそのまま使わず
「生成した質感をトリミングして32×32に切り出し、端をミラーで馴染ませる」後処理を入れます。

### 3.3 オブジェクト・資源

木の実の木（実あり/なし）、枯れ木、畑（未耕/耕済/実り）、釣り場の波紋、水草、
花3種、岩2種、巣3種（うさぎ穴／鳥の巣／草の寝床）、ベンチ、花壇、ランタン、看板、
橋（建設中3段階＋完成）、井戸、天文台 = **約35枚**

### 3.4 UI・エフェクト

吹き出し（9スライス素材）、タマゴ5種、懐き度ハート、天気アイコン4、時間帯アイコン4、
足跡マーカー、パーティクル（雨粒／霧／きらきら／葉っぱ）、ボタン枠 = **約25枚**

**合計の生成回数見積り: 約150回**（キャラシート52 ＋ タイル38 ＋ オブジェクト35 ＋ UI25）

## 4. ディレクトリとファイル命名

```
packages/client/public/assets/
├── atlas/
│   ├── chars.json / chars.png       # ペット・動物・プレイヤー
│   ├── terrain.json / terrain.png
│   └── ui.json / ui.png
└── raw/                              # 生成直後のPNG（gitに入れる。再生成のコスト回避）
    ├── pet_mofi_s_sheet.png
    ├── critter_rabbit_e_sheet.png
    └── tile_grass_01.png
```

命名規則: `{category}_{name}_{dir}_{variant}.png`

- category: `pet` / `critter` / `player` / `tile` / `obj` / `ui` / `fx`
- dir: `n` / `e` / `s` / `w`（不要なものは省略）
- フレーム名（アトラス内）: `pet_mofi_s_walk_0` 〜 `_3`

`species` の値（`03_データモデル.md`）とファイル名の `name` を**一致させる**ことで、
描画側は `atlas[`${a.species}_${a.facing}_${a.anim}_${frame}`]` で引けます。

## 5. 後処理（`tools/pack-assets.ts`）

```
raw/*.png
 → 1) 透過チェック（四隅のalphaが0でなければ警告）
 → 2) シートのスライス（等間隔／自動検出）
 → 3) 不要な透明余白のトリム＋アンカー記録（足元中央をアンカーにする）
 → 4) 指定サイズへリサイズ（キャラ48px、タイル32px）
 → 5) アトラスへパッキング（maxrects）＋ JSON 出力
 → 6) pngquant 相当の減色圧縮（256色）
```

依存を増やしたくないので画像処理は `sharp` 1つに絞ります（リサイズ・トリム・合成・圧縮すべて可）。

## 6. 品質チェックリスト（生成物を採用する前に確認）

- [ ] 背景が**完全に**透明（半透明の白カスが残っていないか）
- [ ] 輪郭線の色と太さが基準トーンと揃っている
- [ ] 足元の接地位置が他キャラと揃う（アンカー調整で吸収できる範囲か）
- [ ] 4方向で同一個体に見える（色・模様・大きさ）
- [ ] walk 4コマで足の動きが循環している（1↔3が対になっているか）
- [ ] 32pxや48pxに縮小しても何のキャラか判別できる
- [ ] 隣り合うタイルで継ぎ目が目立たない

確認はPlaywright（headless MCP）で `?tool=sheet` の一覧ページを開いてスクリーンショットし、
並べて比較します。宣伝資料の画像と並べたコンタクトシートを作るのが確実です。

## 7. フォールバック

アセット生成が追いつかない間も開発を止めないため、**プレースホルダ生成器**を先に作ります。
`tools/placeholder.ts` が種別ごとに色違いの丸＋文字のPNGを吐き、アトラス構造は本番と同一。
これによりM1〜M3はアセットなしで進行でき、絵の差し替えはアトラスの入れ替えだけで済みます。
