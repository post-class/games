## 結論（3行）

1. **機能の欠落はほとんど無い。** 宣伝資料が謳う中身（自律する住民・LLMペット・記憶・噂・共同建設・
   オフライン進行・マルチ）はすべて動いていた。減っているのは「記念撮影／友だちの区画」だけ。
2. **乖離のほぼ全部が「絵」と「演出」。** 地面が単色ベタ塗り・遷移タイル無し・装飾無し・
   接地影無し・夜が暗くならない・光源が光らない・家や風車や噴水が島に一つも無い。
   結果として画面の大半が「無地の緑」になり、宣伝資料の情報密度と決定的に違う。
3. **視点が違う。** 宣伝資料は「2Dクォータービュー」と明記しているが、実装は真上からのトップダウン。
   ここだけは作り直しに相当するので、**実装に合わせて宣伝資料の表記を直す**方針を推奨（→ A-1）。

### 残っているもの

**追加実装として残っているものはありません。** P1・P2 の39件すべてが ✅ または ❌（やらないと決めた）です。

将来やるとしたら、上の「コードは完了・絵だけ不採用 3件」に**手描き or プログラム生成で絵を用意する**ことだけです
（生成AIでは作れないと結論が出ています）。

`reconnect.e2e.ts` の間欠失敗（15〜25%）は原因を特定して解消しています:
`goOffline` が `setOffline(true)` を先に呼んでいたため、`ws.close()` のハンドシェイクが完了できず
`onclose` がページに飛ばないことがあった（**閉じてからオフラインにする**順に直した）。
16回連続パス・実行時間 2.0分 → 47秒。詳細は `ai-pet/AI_CODING.md` §12。
