# 宣伝用資料との乖離是正プラン

宣伝用資料 `docs/01_ゲーム宣伝用資料/index.html` と、実装済みの『ぽこもふ島』を
**実際にプレイして比較**し、埋めるべき差を洗い出したプランです。

- 調査日: 2026-08-08
- 調査方法: playwright-headless で実サーバ（`--llm=real` / seed=`pokomofu-2`）に接続し、
  昼・夕・夜・雨、広場・平原・海岸・建設予定地、PC 1280×720 とスマホ 390×844 を実プレイしてキャプチャ
- 実装の現在地: `PROGRESS.md`（M8まで実装完了・デプロイ未実行）

## 結論（3行）

1. **機能の欠落はほとんど無い。** 宣伝資料が謳う中身（自律する住民・LLMペット・記憶・噂・共同建設・
   オフライン進行・マルチ）はすべて動いていた。減っているのは「記念撮影／友だちの区画」だけ。
2. **乖離のほぼ全部が「絵」と「演出」。** 地面が単色ベタ塗り・遷移タイル無し・装飾無し・
   接地影無し・夜が暗くならない・光源が光らない・家や風車や噴水が島に一つも無い。
   結果として画面の大半が「無地の緑」になり、宣伝資料の情報密度と決定的に違う。
3. **視点が違う。** 宣伝資料は「2Dクォータービュー」と明記しているが、実装は真上からのトップダウン。
   ここだけは作り直しに相当するので、**実装に合わせて宣伝資料の表記を直す**方針を推奨（→ A-1）。
