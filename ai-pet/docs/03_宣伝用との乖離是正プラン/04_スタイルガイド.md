追加・差し替えするアセットはすべてこの基準に従います。
`img-gen-gpt` の生成プロンプトは、この文書の「生成プロンプトの雛形」を引用して組み立ててください。

- 決定日: 2026-08-08
- 基準にした資料: `docs/01_ゲーム宣伝用資料/index.html` の `:root` と `images/*.png`

---

## 1. 視点（A-1 の決定）

**トップダウン（真上見下ろし）を維持する。**

- 理由: クォータービュー化は tilemap の焼成・camera の座標変換・sprites の深度ソート・
  minimap・movement の当たり判定・既存アセット62枚のすべてが作り直しになり、M0〜M8と同規模になる。
  一方、宣伝資料との印象差は視点より **地面の情報量・接地影・時間帯の演出** から来ている
- 代わりに「**クォータービュー風の絵柄**」で寄せる:
  - **キャラクター**: 正面顔のまま。真上から見た形にはしない（宣伝資料も正面顔）
  - **建物・大きな設置物**（家・風車・井戸・噴水・天文台・ベンチ）: **軽い斜め見下ろし**で描く。
    正面の壁と屋根の上面が両方見える角度。屋根の見え方で立体感を出す
  - **地面のタイル**: 真上から。斜めにしない（タイルの継ぎ目が破綻するため）
  - **全員に接地影**を入れる。影が立体感の主役になる
- 宣伝資料の `GRAPHICS` 表記は `2D トップビューの手描き風タイル` に直す（→ H-1）

## 3. 線と形

- 輪郭線は `--ink`（`#4a3b2a`）。**黒は使わない**
- 線幅は 48px 枠のキャラで 2〜3px相当、32px 枠のタイル装飾で 1〜2px相当
- 角は丸く。宣伝資料はすべて角丸（`border-radius` が全体で 14〜30px）
- キャラの目は大きい黒丸＋白いハイライト1点。口は小さく

---

## 4. 彩度の基準

M8 で草地・森タイルの彩度が宣伝資料より高く、**HSV の S だけ 0.78倍**して合わせました。
**この 0.78 を全タイルの基準**とします（V は触らない。草地と森の見分けは明度で付いているため）。

- 既存の未処理分: `tile_dirt` が S=0.687 と高め → 同じ処理を掛ける（A-2 の作業に含める）
- キャラクター・オブジェクトには掛けない（地面より前に出したいので彩度は高いままでよい）

---

## 5. 接地影（D-1）

**スプライトに焼き込まない。** 描画時に1枚の `Graphics` へまとめて描きます。

| 項目 | 値 |
|---|---|
| 形 | 楕円 |
| 色 | `rgba(74, 59, 42, 0.26)`（`--ink` の26%）。**0.18 では実機でほぼ見えなかった**ので上げた |
| 幅 | キャラ幅 × 0.6 |
| 高さ | 幅 × 0.38 |
| 位置 | スプライトのアンカー（`ANCHOR_Y = 43/48`）の位置 |
| 睡眠中 | 高さを 0.6倍に潰す |
| 歩行中 | 上下のバウンドに**追従させない**（影は地面に残る） |

## 6. サイズと足元合わせ

`tools/install-assets.py` の既存ルールを踏襲します。

| 種別 | 枠 | 備考 |
|---|---|---|
| 地形タイル | 32×32 | 継ぎ目が出ないよう端まで塗る |
| 装飾デカール | 32×32 | 透過。中央寄せ |
| キャラクター | 48×48 | 足元が y=43 に来るよう揃える |
| 小さい設置物（ベンチ・花壇・灯り・看板） | 48×48 | 実表示は `objects.ts` の `SCALE` で調整 |
| 大きい設置物（家・風車・井戸・噴水・天文台） | 96×96 | `SCALE` で 2.0〜3.0 相当に置く |

- `_w` は `_e` の左右反転で生成する（新規生成しない）
- 生成後の手直しは**まず Pillow の後処理で解決を試す**（M8では接地影の除去・彩度調整を$0で解決した）

## 7. 生成プロンプトの雛形

```
A single <対象> for a cozy 2D top-down slow-life browser game, hand-drawn storybook style,
soft pastel palette (cream #fffdf3, grass #d9ee94, ink outline #4a3b2a),
thick rounded dark-brown outlines, flat shading with one soft shadow tone,
no gradient background, transparent background, centered, no text, no drop shadow on the ground.
<種別ごとの追記>
```

種別ごとの追記:

| 種別 | 追記 |
|---|---|
| キャラクター | `facing <direction>, front-facing cute face with large black eyes and a small mouth, chibi proportions` |
| 建物・大きな設置物 | `slight three-quarter top-down view so both the roof top and the front wall are visible` |
| 地形タイル | `seamless tileable texture, viewed straight from above, subtle color variation, no outline on the edges` |
| 装飾デカール | `tiny isolated detail, viewed straight from above, small enough to sit inside one 32px tile` |

⚠️ **`gpt-image-1-mini` は一部オプション非対応**です。制約は `img-gen-gpt` スキルの前提を参照してください。
⚠️ 接地影は D-1 で描画側が付けるので、**アセットに影を焼き込ませない**こと
（M8では焼き込まれた影をフラッドフィルで除去する手間が発生した）。

## 9. やらないと決めたこと（決定の記録）

### C-5 川は作らない（2026-08-08 決定）

宣伝資料が「川むこうの木の実」「川辺で自然に出会う」と書いていたが、**島に川は作らない**。

- 川を作って得られるのは「橋の予定地が増える」ことだけ。
  既定 seed（`pokomofu-2`）には橋・井戸・天文台の予定地が**すでに3件そろっている**ので、
  共同建設は今のままで体験できる
- 一方、水路を通すと `worldgen` の「到達不能な陸 0」の保証を作り直すことになり、
  歩ける面積が変わるので `sim:long` でのバランス再検証も必要になる。**費用に対して得るものが小さい**
- 代わりに**宣伝資料の表現を実装に合わせた**（→ H-3）:
  「川むこう」→「岬のむこう」／「川の向こう」→「島の北がわ」／「川辺」→「海辺」

### B-1 タイルのバリエーションは絵を作らない（2026-08-08 決定）

生成アセットでは「32pxに縮小して模様が残る粗さ」と「タイリングが壁紙にならない繊細さ」が
**両立しなかった**（実機で草地の格子が見えて無地より悪化した）。
地面の情報量は **B-3 の装飾デカール**（座標ハッシュで散らすので繰り返しが出ない）に任せる。
コードは残してあるので、良い絵が用意できれば有効になる。詳細は `ai-pet/AI_CODING.md` §9。

### G-3 「友だちの区画」は作らない（2026-08-08 決定）

宣伝資料の「おでかけ：友だちの区画へ遊びに行き、記念撮影」のうち、
**区画（プレイヤーごとの土地）は設計に無い概念**なので作らない。
「記念撮影」だけを実装し、資料の表現を「気に入った風景を1枚の絵として残せる」に変えた（→ H-1）。
