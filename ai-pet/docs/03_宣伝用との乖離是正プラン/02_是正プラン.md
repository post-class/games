# 02 是正プラン（進捗管理表）

このファイルが**唯一の進捗管理表**です。作業のたびに「状態」と「メモ」を書き換えてください。
凡例: ⬜未着手 / 🚧進行中 / ✅完了 / ⏸保留 / ❌やらないと決めた

優先度: **P0**=これが無いと宣伝資料と別のゲームに見える / **P1**=印象を大きく上げる / **P2**=あると良い

各タスクの具体的な手順は `03_タスク詳細.md` の同じIDを見てください。

## 完了の判定（このプラン全体のゴール）

次の3つが揃ったら完了とします。

1. `01_調査結果.md` の各キャプチャと**同じ座標・同じ時間帯・同じ天気**で撮り直したものを並べ、
   すべて「宣伝資料と同じゲーム」に見える
2. **H-2 が終わっている**（宣伝資料の画面イメージが実スクリーンショットに置き換わっている）
3. `npm run typecheck` / `npm test` / `npm run test:e2e` がすべて通り、
   初回ロードが5MB以内・10秒以内、スマホ30fps以上を維持している（M8の完了条件を壊していない）
