# ストーリー改善 実装手順書（THE VEIL FRONT 移行）

- 対象リポジトリ: `multi-commander/`
- 目的: 現行の Wing Commander 模写ストーリーを、新設定「THE VEIL FRONT」（五勢力／ヴェガ宙域／十章キャンペーン）へ差し替える。
- この文書の位置づけ: AIが1タスクずつ実行・検証・進捗更新するための作業台帳。仕様の正典は下記の名鑑HTML。

## 0. 作業の進め方（AI向けルール）

1. 着手前に **§2 ギャップ表** と **§3 事前確認事項** を読む。P0が未決のタスクには着手しない。
2. タスクは **ID順** に1件ずつ実行する。依存関係が明記されているものは依存先の完了を確認する。
3. 1タスク完了ごとに、本書の該当チェックボックスと **§9 進捗表** を更新する（`[ ]`→`[x]`、状態欄を記入）。
4. 各タスクの「検証」を必ず実行し、結果を §9 の備考に1行で記録する。失敗を残す場合は原因を書く。
5. コード規約・ブラウザ確認ルールは `multi-commander/AI_CODING.md` に従う（ブラウザは同時1、chrome-devtools MCP を使用、一時ファイルは `.tmp/`）。
6. 既存の canon / expanded キャンペーンは**壊さない**。新ルートは追加として実装する（§3 P0-3）。
7. 大規模置換は行わず、フェーズ単位でビルド・テストが通る状態を保つ。

## 3. 事前確認事項（P0：決定してから着手する）

### P0-1【要修正】人物名鑑に、物語の主要人類12名が存在しない

`spec/登場人物_人物名鑑.html` のデータ生成部で、人類の名簿が次のように再構成されている。

```js
const japaneseHumanCandidates = factions[0].people.slice(20);
factions[0].people = [ ...japaneseHumanCandidates, /* 欧州系〜アジア系16名 */ ];
```

`slice(20)` により、配列先頭20名が名簿から**落ちている**。落ちた20名には、十章作戦記録が主要人物として指定している次の12名が含まれる。

| 物語での役割 | 名前 | 名鑑での状態 |
| --- | --- | --- |
| 主人公候補（F-54専任） | 朝倉 澪 / 神谷 隼人 / アミナ・オカフォー / マーカス・ジョンソン / プロイ・スリスック | 欠落（5名全員） |
| 艦長 | ウィリアム・ハート | 欠落 |
| 航法・門解析 | ソフィー・ローラン | 欠落 |
| 基地防衛司令 | キム・ソヨン | 欠落 |
| 救難艇 | クレア・ベネット | 欠落 |
| 電子戦 | 小林 直子 | 欠落 |
| 航空団参謀 | ニア・ウィリアムズ | 欠落（Nia Okoye は別人） |
| 爆撃機 | オマル・ラーマン | 欠落 |

- 名鑑の本文には「主人公は…F-54専任パイロット5名から選択する」と書かれており、**HTML内部で本文とデータが矛盾している**。データ側の不具合と判断できる。
- 影響: 肖像画像も最終名簿基準（`assets/characters/regenerated_portraits/confed-01.png` = 相沢 紗良）で採番されているため、上記12名の肖像が存在しない。
- 推奨対応: **名鑑側を修正**し、上記12名を人類名簿に復帰させる（36名の枠を維持するなら差し替え対象を選定）。肖像は不足分を `img-gen-gpt` で追加生成。
- 実装への影響: F2・F5・F7が全面的に依存する。**未決のうちは T2-1 以降に着手しない。**
- 暫定方針（決定が保留された場合）: 物語spec（正典1位）の名前を正とし、名鑑は後追い修正とする。

### P0-2 非人類4勢力の実装範囲

- 世界観specは「confed / kilrathi は維持。他4勢力をゲーム実装で敵・味方として追加することは本資料で決定しない」と明記。
- 一方、十章は第3章（セレシオン護衛船）・第4章（オルド重力アンカー）・第6章（ニューロウム中継器／ドローン）・第8章（三勢力の援護）・第10章（共同艦隊）で**非人類の実体が戦場に必要**。
- 推奨（A案）: `Faction` を5勢力＋`neutral` に拡張し、敵対関係を表で定義。非人類の機体は各勢力2〜3機（章に必要な分）だけ実装し、残りは名鑑資料のまま。
- 代替（B案）: `Faction` は現状維持。非人類は `neutral` として実装し、勢力差は表示ラベルと色で表現。改修は小さいが、第10章の共同艦隊で敵味方判定が破綻しやすい。
- **決定: ( A案 / B案 ) ← 記入**

### P0-3 既存キャンペーン（canon / expanded）の扱い

- 推奨: `CampaignMode` に `'veil'` を追加し、新規戦役の既定にする。canon / expanded は既存セーブ互換のため残す（タイトル画面から選択可能なままにする）。
- 代替: 旧2モードを削除して veil のみにする（テスト・セーブ移行の作業量が増える）。
- **決定: ( 追加 / 置換 ) ← 記入**

### P0-4 キルラシー機の名称

- 名鑑の帝国機は KF01 レオンファング〜KF06 タロンで、現行の salthi / dralthi / krant / gratha / jalthi / dorkir / ralatha と対応しない。
- 推奨: 既存の性能データを維持したまま**表示名とidを新名称へ差し替える**（例 `dralthi`→`kf03-greyhaul`）。第5章の決闘は名鑑どおり KF03 グレイハウル 対 F-44A ラピアーII とする。
- **決定: ( 差し替え / 新規追加して併存 ) ← 記入**

```ts
// src/app/narrative.ts
export interface NarrativeState {
  /** 帰還者名簿。最終無線で読み上げる（重複しない名前の配列） */
  returnees: string[];
  /** 航路信頼 0..100。セレシオン／オルドの支援内容を決める */
  routeTrust: number;
  /** 軍令信用 0..100。搭載兵装・僚機・司令部の無線を決める */
  commandTrust: number;
  /** 敵エースの誓約 0..100。ラギティカ／ヴァルカーンの協力条件を決める */
  aceOath: number;
  /** 章ごとの選択結果 chapterId -> choiceId */
  choices: Record<string, string>;
}
```

| 状態 | 上がる行動 | 下がる行動 | 画面上の変化 |
| --- | --- | --- | --- |
| 帰還者 | 救難、僚機援護、発砲回避 | 追撃、戦果優先 | 格納庫の会話、僚機の出撃可否、最終無線 |
| 航路信頼 | 中立規約の順守、証拠公開 | 民間損害、協定違反 | セレシオン／オルドの支援内容 |
| 軍令信用 | 命令順守、損害の最小化 | 無許可出撃、内部告発 | 搭載兵装・僚機・司令部の無線 |
| 敵エースの誓約 | 決闘規約の尊重、救難優先 | 撃墜後の侮辱、降伏者の放置 | ラギティカ／ヴァルカーンの協力条件 |

実装規約: 難易度は上下させない。**味方の顔ぶれ・援護・搭載兵装・無線内容だけを変える。**
