# ストーリー改善 実装手順書（THE VEIL FRONT 移行）

- 対象リポジトリ: `multi-commander/`
- 目的: 現行の Wing Commander 模写ストーリーを、新設定「THE VEIL FRONT」（五勢力／ヴェガ宙域／十章キャンペーン）へ差し替える。
- この文書の位置づけ: AIが1タスクずつ実行・検証・進捗更新するための作業台帳。仕様の正典は下記の名鑑HTML。

## 0. 作業の進め方（AI向けルール）

1. 着手前に **§2 ギャップ表** と **§3 事前確認事項** を読む。P0が未決のタスクには着手しない。
2. タスクは **ID順** に1件ずつ実行する。依存関係が明記されているものは依存先の完了を確認する。
3. 1タスク完了ごとに、本書の該当チェックボックスと **§9 進捗表** を更新する（`[ ]`→`[x]`、状態欄を記入）。
4. 各タスクの「検証」を必ず実行し、結果を §9 の備考に1行で記録する。失敗を残す場合は原因を書く。
5. コード規約・ブラウザ確認ルールは `multi-commander/AI_CODING.md` に従う（ブラウザは同時1、chrome-devtools MCP を使用、一時ファイルは `.tmp/`）。
6. 既存の canon / expanded キャンペーンは**壊さない**。新ルートは追加として実装する（§3 P0-3）。
7. 大規模置換は行わず、フェーズ単位でビルド・テストが通る状態を保つ。

### P0-1【要修正】人物名鑑に、物語の主要人類12名が存在しない

`spec/登場人物_人物名鑑.html` のデータ生成部で、人類の名簿が次のように再構成されている。

```js
const japaneseHumanCandidates = factions[0].people.slice(20);
factions[0].people = [ ...japaneseHumanCandidates, /* 欧州系〜アジア系16名 */ ];
```

`slice(20)` により、配列先頭20名が名簿から**落ちている**。落ちた20名には、十章作戦記録が主要人物として指定している次の12名が含まれる。

| 航法・門解析 | ソフィー・ローラン | 欠落 |
| 基地防衛司令 | キム・ソヨン | 欠落 |

- 名鑑の本文には「主人公は…F-54専任パイロット5名から選択する」と書かれており、**HTML内部で本文とデータが矛盾している**。データ側の不具合と判断できる。

- 実装への影響: F2・F5・F7が全面的に依存する。**未決のうちは T2-1 以降に着手しない。**
- 暫定方針（決定が保留された場合）: 物語spec（正典1位）の名前を正とし、名鑑は後追い修正とする。

export interface NarrativeState {
  /** 帰還者名簿。最終無線で読み上げる（重複しない名前の配列） */
