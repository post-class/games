# THE VEIL FRONT 宇宙年表

統合暦 0 年は西暦 2181 年に始まる。ゲーム開始時点は統合暦 131 年／西暦 2312 年の「ヴェガ非常事態」である。十章作戦は統合暦 132 年／西暦 2313 年に終わり、後世年表は西暦 2412 年までを扱う。

この資料では、五勢力を異なる人類史・宗教的世界観の**構造**から再設計する。参照するのは、統治の成立と崩壊、外来文化の受容、交易、信仰、移動、植民、解放と再統合の過程である。現実の民族・宗教・地域を、異星種族の性格や能力へ対応させるものではない。

## 年表の読み方

- 勢力列の名称は、統合暦 131 年時点の呼称で統一する。それ以前の欄には、その勢力の前身国家・共同体も含む。
- 統合暦以前の「基層史」は、各文明が 0 年の時点ですでに背負っている歴史である。長い歴史を 131 年間へ無理に圧縮しない。
- 統合暦 0 年以後は、五つの歴史がヴェイルを介して接触し、互いの改革・繁栄・支配・解放を連鎖させる時代として描く。
- 既存設定由来の8事件（0、8、16、27、48、65、92、131年）は歴史の錨として残し、その間をつなぐ事件と各勢力の背景を本改訂で追加した。
- 同じ勢力の内部にも複数の立場がある。現在の戦争を「善い文明と悪い文明」の対立にはしない。
- 2313 年以後の後世年表は、第10章で「五者共同管理」が選ばれた場合を基準史とする。ゲーム内の三つの結末は維持し、ほかの結末は並行し得た歴史として扱う。
