# 人類史：五つの歴史圏の比較年表

物語の参照用に、日本史と、異なる政治・宗教・交易の力学を持つ四つの歴史圏を、同じ西暦軸で比較する。

| 歴史圏 | 主な参照点 |
| --- | --- |
| 日本史 | 島嶼社会、外来文化の受容、朝廷と武家政権、近代化 |
| 東アジア大陸史 | 主に中国史。統一帝国と分裂、官僚制、周辺勢力との関係 |
| 地中海・ヨーロッパ史 | 都市国家、共和政と帝政、宗教権威、革命と工業化 |
| 西アジア・イスラム圏史 | 古代オリエント、ペルシア、イスラム諸王朝、交易と多民族帝国 |
| アフリカ・アメリカ・大西洋世界史 | 先住民文明、植民地化、奴隷制、独立、脱植民地化 |

> **表記**：`前` は紀元前、`頃` は年代に幅がある出来事を示す。`—` は、この比較年表では特記しない。個別地域の全史ではなく、物語づくりで参照しやすい転換点を抜粋した。
