## 第1部 レビュー

### 総評

このプレゼンは「よく設計された企画書」だが「物語」になっていない。
各章の論点、五勢力の内部対立、選択と代償の対応表は、企画資料としては水準が高い。問題は、それが**誰の体験でもない**ことだ。三十枚を通して主語が「プレイヤー」という無人称のままで、名前も顔も、失うものもない。

`魅力あるストーリーとは.md` の骨格に照らすと、欠けているのは中央の三つである。

| 要素 | 現状 |
| --- | --- |
| 人物 | △ 各章の異文明側は魅力的。だが**主人公が存在しない** |
| 目的 | ○ 章ごとに明確 |
| 対立 | ◎ 十章すべてに用意されている |
| 賭け金 | ✕ 失うのが毎回「記録・信用・評価」で、**具体的な喪失が一度もない** |
| 選択 | ○ 提示されている |
| 変化 | ✕ 主人公がいないため、**誰の価値観も変わらない** |

以下、重い順に指摘する。

---

### 指摘1（最重要）　視点人物がいないので、感情が乗る場所がない

三十枚のなかで「プレイヤー」は9回登場するが、名前も階級も年齢も与えられていない。会話する相手は全員が幹部・専門官である。

現状の主要人物17名の内訳を見ると、パイロットは**桐谷 綾ただ一人**だ。

- 連邦側9名：艦隊司令、基地防衛官、航法主任、電子戦士官、救難艇長、空母戦術官、情報作戦士官、外交連絡士官、**近接護衛パイロット（桐谷 綾のみ）**
- 他勢力8名：指揮者、翻訳者、戦術官、合議王、原初核、通信アンドロイド、決闘士、儀礼通信士

空戦ゲームの物語なのに、飛ぶ人間がほぼいない。結果として全章が「作戦室と会議室の話」になり、Wing Commander の強み——僚機の声、格納庫の空気、帰ってこなかった機体の空き枠——が丸ごと欠落している。

### 指摘2（ユーザー指摘の一般化）　「移動の一段落」が全章で抜けている

第一章の `story-detail` は「現場で待っていたのは、輸送船に取り付いたキルラシー先遣隊三機と……」で始まる。しかし直前の `lead` は「輸送船〈アストラ・メイ〉が救難信号を発した」で終わっており、**誰かが現場へ向かった記述が一度もない**。読者は突然、行った覚えのない場所に立たされる。

同型の飛躍が全章にある。

| 章 | 飛躍している箇所 | 抜けている情報 |
| --- | --- | --- |
| 1 | 「現場で待っていたのは」 | 誰が、いつ、何機で出撃したか |
| 2 | 「回収された帰還者は三人」 | 誰がどこへ行って回収したのか（順序も逆：回収→司令部の不承認、と書かれている） |
| 3 | 「アウルが求めたのは増援ではなく」 | アウルが誰に、どの場で要求したのか。連邦がなぜ応じる立場なのか |
| 4 | 「連邦の契約船は……縫い止められた」 | 契約船が何のために採掘帯にいたのか |
| 6 | 「中継器の中枢で応答した原初核クラウン」 | 中枢へどうやって到達したのか |
| 7 | 「六つ目の条項があった」 | 誰がどこで発見したのか（第二章の帰還者証言との接続も不明） |
| 9 | 「迷路の中心にはラギティカとクラウンがいる」 | なぜ二人がそこにいるのか |

**原因は物語ではなくテンプレートにある。**「前説＝状況と論点／本節＝ミッションと選択」という枠に時系列の出来事を詰め込んだため、出来事のあいだの移動・経過・因果が押し出されている。

### 指摘3　十章すべてが同じ形なので、三章目から展開が読める

全章が次の三拍で書かれている。

1. 異文明（または味方の専門官）が、正当な理由を静かに述べる
2. 味方が数字で反対する（時間・燃料・人数）
3. どちらを選んでも代償が残り、記録だけが次章へ持ち越される

一章では効くが、十回繰り返すと「今回もどちらも正しくて、記録が残るのだろう」と先読みできてしまう。緊張が消える。台詞のリズムまで同型で、`quote` が全章「静かな警句」に揃っている。声の高低差がない。

### 指摘4（最重要）　十章通して誰も死なず、何も失われない

「帰還者名簿」がテーマの物語なのに、**名簿に載らなかった者が固有名で一度も出てこない**。

- 第一章：脱出ポッドの生命維持が切れる可能性は書かれるが、切れた人間の名は出ない
- 第四章：契約船の空気が十九時間と書かれるが、間に合わなかった結果は書かれない
- 第九章：「格納庫では、第一章で拾えなかった者が笑っている」——ここで初めて喪失が示唆されるが、**その人物を読者は知らない**ため何も刺さらない

喪失がないので、第十章の名簿読み上げが感情の頂点になりえない。「誰を帰すかを決める出撃だ」という最終命令は、帰らなかった者を一人も見せていない物語の中では、標語にとどまる。

### 指摘5　語彙が抽象名詞に偏り、体感がない

プレゼン全体で頻出する語：記録、検証、書式、手続き、同意、整合性、前例、通貨、位相、判断、義務。

対して、身体で分かる語がほとんどない。汗、酸素、Gの重さ、焦げた匂い、無線の雑音、震える手——こうした語が三十枚にほぼ存在しない。「情報は次の航路を開くかを決める通貨として、戦争全体を動かし始める」（第二章）のような文が象徴的で、事務文書の語彙で戦争が語られている。

### 指摘6　キルラシーが善玉に寄り、急進派に顔がない

帝国側はラギティカ（決闘士）とヴァーク（儀礼通信士）の二名だけで代表される。二人はどちらも誓約を守る善良な側だ。一方、七章で暴かれる真の敵「灰冠急進派」は組織名のまま、顔も理由も与えられない。

結果、「五つの文明がそれぞれ内部対立を抱える」という年表の設計が、プレゼンでは半分しか実現していない。名鑑には未使用の帝国キャラが8名おり、なかでも**セイラク（灰冠近衛隊長・雌33歳／宗家の旗艦を救うため陽動と潜入で三個中隊を足止め）**は、忠義ゆえに急進派に付く敵として完璧な履歴を持つ。

また、四勢力の最高権力者のうち**アーク（オルド合議王）とクラウン（原初核）は登場するが、ヴァルカーン（大牙王）とマザー（セレシオン古唱母）が一度も出てこない**。第八章の五者署名の場に、五勢力の最終決定権者が揃っていないのは構成上も弱い。

### 指摘7　最大の反転（第七章の共犯関係）が組織どまりで、裏切りになっていない

「連邦軍需企業と帝国急進派が八十三年間、同じ資産を守っていた」——設定としては強い。だが犯人が法人なので、感情としては何も起こらない。プレイヤーが信頼していた個人が関わっていなければ、これは裏切りではなく報告書である。

### 指摘8　クライマックスが「書類を届ける」「回線を守る」で地味

第七章＝期限内に箱を届ける、第八章＝六十秒回線を守る。空戦の見せ場としては弱く、盛り上がりの実質的なピークは第九章の位相迷路まで来ない。八章が停戦（＝緊張の緩和）である構成も、九〜十章の再加速を難しくしている。

### 指摘9　人物紹介スライド10枚が、直前2枚の要約になっている

30枚中10枚が人物紹介だが、`cast-profile` の説明文が名鑑の戦績＋前説の再掲になっており、新しい情報がほぼない。`quote` も同一章の前説・本節と重複している（第1章「撃つ前に、拾える者を拾え」は2回、第4・8章も重複）。三十枚の三分の一が実質的に情報ゼロで、テンポを落としている。

### 指摘10　資料間の不整合（要判断）

| 内容 | 状況 |
| --- | --- |
| `宇宙年表.md` は「連邦のハート艦長が作った〈帰還者名簿〉」と記す | 名鑑の人類36名に **William Hart は存在しない**（名鑑スクリプトが人類リストを再構成した際に落ちている）。名簿の作者を誰にするか要決定 |
| 年表の空母名〈タイガーズ・クロー〉 | Wing Commander の艦名そのもの。「ウィングコマンダーを超える」という目的に対して、固有名の借用は不利 |
| 名鑑にいない人物（朝倉 澪、神谷 隼人、小林 直子ほか） | 同じ再構成で削除済み。他資料が参照していないか確認が必要 |

### 指摘11　HTML実装上の軽微な点

- `.slide-index` の番号が 03・06・09… を飛ばす（人物紹介スライドに `.slide-index` がない）。現在 `display:none` なので実害はないが、表示に戻した時点で崩れる
- レイアウト自体は 1280×720 で確認済み。破綻・不要スクロールはなく、`personnelValidation` は `passed`。**見た目は問題なく、直すべきは中身**

## 第2部 改訂設計

### 2-1 企画の三軸を確定する

`魅力あるストーリーとは.md` の手順に従い、まず三つを一つずつに絞る。

| 軸 | 決定 |
| --- | --- |
| **主感情（一つ）** | 緊張の末に残る**感動**。「間に合わなかった名前」を抱えたまま飛び続ける痛みと、それでも名簿を読み上げる浄化 |
| **補助感情（二つ）** | 喪失と再生／畏敬（五つの文明の時間尺度） |
| **テーマ** | **「名前を覚えている責任」**。命令は数を数える。主人公は名前を数える。この二つが衝突する |
| **駆動形式** | 戦争 × サバイバル（避難航路）＋ 第2・7章にミステリー |
| **代償と変化** | 主人公は「全員を守る」という信念を第六章で破壊され、第九章で「選べなかった者を忘れない」へ変わる。不可逆 |

一行要約：
**「守ることしかできない23歳の護衛パイロットが、守れなかった者の名前を数え続け、最後に敵味方を分けない名簿を読み上げるまでの十章。」**

### 2-3 名前を持つ喪失を三つ置く

抽象的な「代償」を、具体的な三つの喪失に置き換える。

| --- | --- | --- | --- |
| **A** | **サナ・ベルカ（6歳）** ——第一章で酸素が切れた脱出ポッドの搭乗者。綾が追撃を選んだ側で失われる（または救った側で別の誰かが失われる） | 第1章 | 「三本の時計」が数字ではなく名前になる。第9章・第10章で必ず戻す |

### 2-4 十章の改訂プロット

#### 章ごとの改訂ポイント（現状からの差分）

**第4章 十九時間と千二百年**

- **朔の重傷を追加**。「証拠を選んだ」代償が、次章以降ずっと救難艇の欠員として残る

**第5章 名を名乗る**

**第6章 三秒の遅れ**

### 2-5 書き方のルール（指摘2・3・5への構造的な対策）

#### ルールA　前説スライドの段落構成を固定する

| 位置 | 書くこと |
| --- | --- |
| `lead`（1文） | いつ・どこで・誰に何が起きたか |
| 第1段落 | **誰が、どうやってそこへ向かったか。**（← 現状で丸ごと欠けている段落） |
| 第2段落 | 現場で判明した事実（現状の「現場で待っていたのは」はここに置く） |
| 第3段落 | 艦内の対立と、支払う代償 |

**新しい場所・新しい相手を出すときは、そこへ誰がどうやって行ったかを先に一文書く。** 例外を作らない。

#### ルールB　専門用語は初出時に7〜15字の同格説明を付ける

対象語：ヴェイル、ヴェガ門、門制御核／半核、五者通行協定、位相、共鳴パルス、地層記憶、冊航台帳、誓約語、公証中継所、静穏海、灰冠。

例：「ヴェイル——門と門を結ぶ古代の航路網——の裂け目」

#### ルールC　章ごとに台詞の「声質」を変える（指摘3への対策）

全章が静かな警句になっているのを崩す。

| 章 | 声質 |
| --- | --- |
| 1 | 短い命令形（クワメ） |
| 2 | 疑問形が続く（証言者たち） |
| 3 | ほぼ無言・身体の指示だけ（回廊） |
| 4 | 数字の読み上げ（ニア） |
| 5 | 儀礼文の朗読（ドゥル・ヴァーク） |
| 6 | **叫び／途切れる無線**（澪） |
| 7 | 言い訳と沈黙（三枝） |
| 8 | 五言語が重なる（署名の場） |
| 9 | 反響・繰り返し（位相） |
| 10 | 名前の羅列だけ（名簿） |

#### ルールD　抽象語を具体物に置き換える（指摘5への対策）

| 現状 | 置換の方向 |
| --- | --- |
| 記録が残る | 名簿に鉛筆で書き足される／地層に線が一本増える |
| 検証可能な形 | 五つの書式で同じ一行が読める |
| 生命維持が切れる | 酸素計が赤に変わる／通話に混じっていた息の音が消える |
| 軍令信用を失う | 発艦甲板に並ぶ機体が三機減る |
| 代償を支払う | 高峰が空いた機体枠の油を拭く |

各スライドに**身体で分かる語を最低一つ**入れる。

#### ルールE　人物紹介スライドは「関係の更新」だけを書く（指摘9への対策）

名鑑の戦績のコピーをやめ、**その章で三人の関係がどう変わったか**だけを書く。`quote` は前説・本節と重複させず、その章で初出の台詞を使う。

### 2-6 画像方針（次段階の作業メモ）

- 人物画像は既存の `docs/assets/characters/regenerated_portraits/<id>.png` をそのまま使用（生成しない）
- 人物以外の20枚は **gpt-image-1-mini** で生成。既存の `assets/vega-emergency-presentation/slide-NN.webp` は 1536×1024 なので同寸に揃える
- 章ごとの色は現行の `--accent` を踏襲するが、**第6章のみ寒色を落として単色に寄せる**（澪の死の章を視覚的に沈める）
- 生成は最大10並列。プロンプトは章タイトルではなく**その章の身体的な一場面**を指定する（例：第6章「三秒遅れた僚機表示のホログラム越しに、破片になった偵察機を見るコクピット内」）

### 2-7 確定が必要な事項（ユーザー判断）

1. **主人公を桐谷 綾（`confed-05`）に確定してよいか。** 本設計はこれを前提にしている
2. **〈帰還者名簿〉の作者をオリヴァー・グラント艦長（`confed-21`）にしてよいか。** 年表の「ハート艦長」は名鑑に存在しないため、いずれ年表側の修正が必要（年表の修正はアプリ実装時と指示されているため、本書では変更していない）
3. **空母名〈タイガーズ・クロー〉を改名するか。** Wing Commander からの借用であり、超えることを目標にするなら不利
4. **東雲 澪（`confed-08`）を死亡させてよいか。** ゲーム側で後続章に登場させる予定があるなら、喪失担当を別人物に差し替える
5. **サナ・ベルカ（6歳・民間避難民）の追加を認めるか。** 名鑑は軍関係者のみのため、名簿に載る民間人は新規名が必要になる。名鑑への追加は行わず、ストーリー内の固有名として扱う想定
