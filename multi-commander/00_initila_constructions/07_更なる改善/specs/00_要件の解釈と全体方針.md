## 1. 「初速は10」の解釈

現状、発艦の初速は 2 か所で決まっている。

| 場所 | 現状 | 意味 |
|---|---|---|
| `src/mission/MissionRunner.ts` の自機 `spawnShip` | `speed = maxSpeed × (easy: 0.5 / それ以外: LAUNCH_THROTTLE)` | ホーネットなら 200 kps（Easy）で空間に出現する |
| `src/app/DeckSequence.ts` `startLaunch()` | `player.vel = 前方 × 60` | カタパルト射出直後の速度を 60 に上書き |

**解釈: 「初速」＝ 実速度（HUD の速度計に出る値）。単位は kps。目標速度（速度設定）は別物。**

したがって W1 は、
- 発艦の瞬間の**実速度**を 10 にする（`spawnShip` の `speed` と `DeckSequence` の両方）
- **速度設定（スロットル値）は現状のまま**（Easy 50% / それ以外 `LAUNCH_THROTTLE`）にする

の2点を同時に満たす。片方だけ変えると次の副作用が出るため、両方を1つの作業として扱う。

- `spawnShip()` は `speed` から `input.throttle` を逆算している（`world.ts:178`）。
  `speed: 10` だけ渡すと速度設定が 2.5% になり、**発艦後に加速しなくなる**。
  06_更なる改善 T2-⑤ で決めた「どの難易度でも巡航速度から始める（気づかないと 100 秒失う事故を無くす）」に反するので、
  `SpawnShipOptions` に `throttle` を追加して速度設定だけ従来値を保つ。

これで「カタパルトから押し出された直後はほぼ静止、そこからエンジンで巡航速度まで伸びる」挙動になり、
要件 6（ちょっと接触して死ぬ）の緩和にもそのまま効く。

## 2. 「コクピットの右・左・上はガラス」の解釈

`src/render/Cockpit.ts` の現状は、開口部（NDC 横 ±0.70 / 上 0.66 / 下 −0.40）の外側を
**不透明な板**（側壁 `FRAME_DARK`、天蓋 `FRAME_DARK`、頬当て `PANEL`）で埋めている。
つまり「風防の外は塗り潰し」であり、ガラスは1枚も無い。

**解釈: 開口部の外側にある「側壁」「天蓋」の面を、骨組み（柱・桁・リブ）を残したまま透明なガラスへ置き換える。**

- 透明にする: 側壁の板、天蓋の板（＝視界を塞いでいる大面積の2種）
- 残す: 柱・斜めの梁・桁・リブ・リベット・計器盤・頬当てコンソール（＝構造物と計器）
- 新設: ガラス用マテリアル 1種（`GLASS`）。ドローコールは +1（マテリアル単位で畳んでいるため）

「ガラスでなかったらガラスという事にして」への対応として、
`docs/機体_機体名鑑.html` の F-54 記述に**気密風防（バブルキャノピー）である**旨を1文追記する（W8）。

## 3. 【回答】第1章でタイガーズ・クローへ帰還する手順

依頼の質問への回答。実装ではなく**現状の正解手順**である（この手順が伝わっていないこと自体が要件 7 の背景）。

1. **NAV 2（救難信号源）で必須目標を片付ける。** 第1章の必須は
   「輸送船〈アストラ・メイ〉を帰投航路に乗せる」「輸送船の生存」「隔壁の5分」「自機の帰投」の4つ
   （`src/content/veil/missions/ch01.ts`）。
2. **輸送船を自機から 5.2km 以内（`AUTOPILOT_ESCORT_RANGE`）に置く。**
   オートパイロットは、この距離内の非敵対の非艦艇を相対位置ごと連れて行く（`src/sim/nav.ts:139`）。
   輸送船は自力で 25km を5分では走れないので、**連れ帰るのが正解**。
3. **半径 4.5km 以内の敵機を片付ける。** `AUTOPILOT_BLOCK_RANGE = 4500`。
   1機でも残っていると `A` は「交戦中はオートパイロットを使えない」で弾かれる。
   小惑星帯・機雷原の中でも使えない（第1章は NAV 1 に岩がある）。
4. **`A` を押す。** 次の未到達 Nav（＝「帰投」、到達半径 1400）へ自動で運ばれる。
   到達すると `着艦を許可する` の無線が出て、勝利時は着艦演出（3.6秒）を経てデブリーフへ移る。
5. 敵が残っていても、**戦闘系の必須目標が済んでいれば離脱できる**（`ignoreHostiles`）。
   片付いていないうちは弾かれるので、まず必須目標を確認する。

**「ちょっと接触しただけで死んだ」の原因**（`src/sim/combat.ts:398-449`）:

- 接触ダメージは `base = 6 + max(0, 相対速度 − 40)² × 0.0016` に、
  **質量比 `min(14, 0.6 + 相手半径/自半径 × 1.6)`** を掛ける。
- 相手が母艦タイガーズ・クロー（`radius` は艦艇なので数百）だと質量比は上限 14 に張り付く。
- 発艦初速 60・母艦 30 なら相対速度 30 → `base ≒ 7.4` → **1回で 104 ダメージ**。
  Easy の `playerDamageTaken 0.55` を掛けても 57。ホーネットは `hull 100 / armor 25 / shield 42`。
  **0.5 秒ごとに再判定**されるので、擦った状態が続けば2〜3回で沈む。
- つまり「ちょっと接触」でも即死級なのは仕様どおりの計算結果であり、バグではない。
  これを Easy で消すのが W2。

## 4. 「味方機とのダメージは Easy の時は 0」の解釈

**解釈: 難易度 Easy のとき、プレイヤー機と非敵対勢力（`isHostile` が false）の接触では、双方のダメージを 0 にする。**

- 対象は接触（体当たり）だけ。**誤射（味方への被弾）は対象外**。
  誤射は第2章の主題（識別）であり、ゼロにすると「民間船に1発当てたら任務失敗」が成立しなくなる。
- 「味方機」は自陣営に限らず、**プレイヤーと敵対していない相手すべて**（母艦・輸送船・救難ポッド・
  セレシオン・オルド・共同作戦中のキルラシー）とする。要件の主因が**母艦との接触**なので、
  自陣営（`confed`）だけに絞ると母艦（`faction: 'neutral'`）が外れて要件を満たせない。
- **押し戻し（`separate`）は残す。** 0 ダメージにしても機体同士がめり込んだままにはしない。
- **敵機との接触は据え置き**（Easy でも体当たりは危険）。
- NORMAL / HARD は 1 も変えない。

## 5. 設定「表示」タブの範囲

新タブに移すのは「見た目」に関する既存項目と、新規のコクピット表示方法。
既存項目は**移動のみで挙動を変えない**（保存キーも変えない）。

| 項目 | 現在のタブ | 移動後 |
|---|---|---|
| コクピット表示 | 操作 | **表示**（後述の3択セレクタへ置換） |
| 被弾カメラ揺れ / 追尾視点の遅延 / アフターバーナー画角 | 操作 | 表示 |
| 無線字幕サイズ / 無線ログの表示時間 | 操作 | 表示 |
| ブルーム / 閃光を抑える / 色覚サポート配色 | オーディオ（誤配置） | 表示 |
| ゲームパッド振動 | オーディオ（誤配置） | 操作 |

オーディオタブは音量3本 + 新規の BGM / 効果音セクションだけにする。

## 6. 「何章の何番目のミッション」の解釈

veil（十章）は 1 章 = 1 ミッションだが、canon / expanded は 1 章に勝ちルート／敗北ルートの
複数ノードがある。よって表示は次の2段構えにする。

- **章**: `第N章 / 全K章`（`campaignNode().chapter` と `totalChapters(mode)` を使う）
- **章内のミッション**: その章に属するノードを安定順で並べた 1-based 序数。
  1本しか無い章（veil の全章）では章内表記を省略する。

表示場所は**出撃中の ESC（ポーズ画面）とブリーフィング画面の2か所**（依頼の指定どおり）。
