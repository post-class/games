## 1. 依存関係

```
W1 発艦初速 ────────────┐

W6 進行表示 ────────────┘
```

## 2. 推奨する着手順

| 段 | 作業 | 理由 |
|---|---|---|
| 1 | **W1 + W2** | 依頼の中で最も体験に直結する（理不尽に死ぬのを止める）。他と衝突しない |
| 2 | **W6** | 変更が小さく、以降の手動テストで「今どこか」が読めるようになる |
| 3 | **W3** | 視界の改善。W4 の前提 |
| 4 | **W4** | 設定タブの再編。ここで `SettingsPanel` の構造を整える |
| 5 | **W5-A → W5-B** | 整えた設定パネルに乗せる |
| 6 | **W7-1** | 用語統一を先に済ませる（あとで文字列を触る箇所が増えないように） |
| 7 | **W7-2** | キー既定の変更。W7-1 で直したチュートリアル文と整合させる |
| 8 | **W7-3 → W7-4 → W7-5 → W7-6 → W7-7** | 機能追加。1つずつ単体テストとブラウザ確認まで済ませる |
| 9 | **W8** | 実装が固まってから文書へ反映する（先に書くと乖離する） |

各段の終わりで `npm test` と `npx vite build` を通す。**通らない段を残して次へ進まない。**

## 3. 完了条件（この 10 個が全部言えたら完了）

1. Easy で第1章に出撃し、**発艦直後の速度が 10 KPS**で、そこから巡航速度まで自機が加速する。
2. Easy で母艦・輸送船・救難ポッドに接触しても**被害が出ない**。押し戻しは働く。
   「ふつう」では従来どおり被害が出る。
3. コクピット視点で、**左右と上がガラス越しに見える**。ガラスの背後の敵機・曳光弾が消えない。
4. 設定の「表示」タブでコクピットの表示方法を**5段階**に切り替えられ、
   選択が保存され、次回起動でも維持される。
5. 設定の「オーディオ」タブで**11 の場面それぞれの BGM を選べ**、
   選んだ曲が実際にその場面で鳴る。「無音」も選べる。
6. 設定の「オーディオ」タブで**9 カテゴリの効果音の音源と音量を選べ**、
   「無音」にしたカテゴリだけが鳴らなくなる。
7. 出撃中に `Esc`、およびブリーフィング画面で、**第N章 / 全K章**（必要なら章内の何本目か）が読める。
8. `+` `-` で速度設定が動き、`]` `[` も従来どおり効く。表示上の用語がすべて**「速度設定」**になっている。
9. `L`（手動ロック）・`;`（目標速度同期）・`I`（照準下ターゲット）・
   `Alt+F/A/B/H/R`（僚機命令）・`/`（後方視点）がすべて動き、
   **既存のキー操作を1つも壊していない**（特に `Alt+A` でオートパイロットが走らない）。
10. `README.md` の操作表・設定の節・グラフィックの節、`docs/機体_機体名鑑.html` の風防記述、
    `キーボード操作方法_修正方針.md` の対応表が実装と一致している。

## 4. 途中で判断が必要になる点（実装者が決めてよい／決めたら記録する）

| 点 | 選択肢 | 推奨 |
|---|---|---|
| ガラスの既定の濃さ | 0（完全素通し）〜 0.25 | **0.1**。ガラスがあると分かる最小限 |
| `;`（目標速度同期）のキー | `;` / `'` / `.` | **`;`**（`L` の隣、未割り当て） |
| 後方視点のキー | `/` / `,` / `.` | **`/`**（押しっぱなしで押しやすい） |
| 後方視点の方式 | 視点反転 / バックミラー小窓 | **視点反転**（描画コストを増やさない） |
| `MUSIC_TRACKS` の扱い | 互換で残す / 全参照を移して削除 | 参照が3か所以下なら**移して削除** |
| 効果音の「控えめ」の係数 | 音量 0.5 / 長さ 0.7 | まず推奨値、実機で耳で決める |
| 味方接触の免除を Normal にも入れるか | 入れない / 0.5 倍で入れる | **入れない**（依頼は Easy のみ） |

## 5. やらないこと（今回のスコープ外。記録して次回へ送る）

- オートスライド（進行方向を保ったまま機首を振る）
- 砲／シールド／エンジンの推力配分（VDU 操作）
- 砲塔視点・砲塔操作
- バックミラー（画面内の小窓としての後方表示）
- 新しい BGM / 効果音ファイルの追加（同梱アセットは増やさない）
- 難易度 Normal / Hard の数値調整

理由と代替案は各手順書に書いてある。次回の依頼を作るときは
[00_要件の解釈と全体方針.md](00_要件の解釈と全体方針.md) §7 と本節を出発点にする。
