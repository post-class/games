## 共通の約束（AI_CODING.md の再確認）

- 表示する値と実挙動は同じ設定値から生成する。表示だけ変えて実挙動が変わらない状態を作らない。
- 難易度補正の対象を明確にする。今回追加する Easy の接触ダメージ免除は
  **プレイヤーと非敵対勢力の接触だけ**に効かせ、NORMAL / HARD の挙動は 1 も変えない。
- 保存データ (`Settings`) に項目を足すときは `settingsVersion` と `normalizeSettings()` を必ず更新する。
- 一時ファイル・キャプチャは `.tmp/` に置く。
- ブラウザ確認は chrome-devtools MCP、同時 1 ブラウザ。1280×720 で確認する。
