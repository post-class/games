| 手順 | 期待 |

### 3-5 W7 — 操作

**`dispatchEvent` ではなく実キー入力で確認する**（AI_CODING.md）。
各操作ごとに「操作前の値 / 押したキー / 直後の期待値 / 画面上の反映」を1行ずつ記録する。

| キー | 期待 |
|---|---|
| `+` 単押し / 押しっぱなし | 速度設定 +10% / 連続増加 |
| `-` 単押し | −10% |
| `]` `[` | 従来どおり効く |
| `;` | ターゲットの速度へ同期し、`announce` に KPS と % が出る |
| `L`（設定「手動」） | ロックが進み始める。押す前は `ロック待機 [L]` |
| `I` | 照準下の相手を掴む。外していれば「照準下に目標なし」 |
| `Alt+F/A/B/H/R` | 僚機へ指示が飛ぶ。通信メニューは開かない。**オートパイロットが同時に走らない** |
| `/` 押している間 | 後方視点。離すと前へ戻る。照準は出ない。速度・目標は出たまま |
| `Esc` | ポーズ（変更なし） |
