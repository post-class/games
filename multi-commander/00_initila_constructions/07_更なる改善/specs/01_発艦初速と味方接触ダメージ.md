# W1 — 発艦時の実初速を 10 にする

## 現状

| ファイル | 行 | 現状のコード | 効果 |
|---|---|---|---|
| `src/world/world.ts` | 176-178 | `const speed = (o.speed ?? maxSpeed*0.5) * speedScale;`<br>`e.vel = 前方 × speed;`<br>`e.input.throttle = min(1, speed / (maxSpeed*speedScale));` | **速度から速度設定を逆算している** |
| `src/mission/MissionRunner.ts` | 536-541 | `speed: maxSpeed * (easy ? 0.5 : LAUNCH_THROTTLE)` | 出現時の実速度 = 巡航速度 |
| `src/app/DeckSequence.ts` | 62-64 | `player.vel = 前方 × 60;`<br>`input.throttle = 0;` | カタパルト射出直後 60 kps |

## あるべき姿

- 発艦の瞬間の**実速度は 10 kps**。HUD の速度計も 10 から始まる。
- **速度設定（目標速度）は従来値のまま**（Easy 50% / それ以外 `LAUNCH_THROTTLE`）。
  発艦演出が終わった時点でエンジンが巡航速度まで伸ばしていく。
- 母艦・待機列の民間船との接触で即死する確率が下がる（相対速度が下がるため base ダメージも下がる）。

## 手順

### 手順 1-1 `SpawnShipOptions` に `throttle` を追加する

`src/world/world.ts`

1. `SpawnShipOptions`（133 行付近）へ追加する。

```ts
  /** 初速 (未指定なら前方へ maxSpeed*0.5) */
  speed?: number;
  /**
   * 出撃直後の速度設定 (0..1)。
   * 未指定なら `speed` から逆算する（従来挙動）。
   * 実速度と速度設定を別に決めたいとき（カタパルト発艦: 実速度 10 / 速度設定は巡航）に使う。
   */
  throttle?: number;
```

2. 176-178 行を次のように変える。

```ts
  const speed = (o.speed ?? o.def.maxSpeed * 0.5) * rt.speedScale;
  e.vel.set(0, 0, -1).applyQuaternion(quat).multiplyScalar(speed);
  e.input.throttle =
    o.throttle !== undefined
      ? clamp01(o.throttle)
      : Math.min(1, speed / (o.def.maxSpeed * rt.speedScale));
```

`clamp01` は `src/core/math.ts` にある。未 import なら追加する。

**壊してはいけないこと**: `throttle` を渡さない既存の呼び出し（敵機・僚機・護衛対象・母艦）は
逆算のまま。`tests/ut` の既存スポーン系テストの期待値は変わらない。

### 手順 1-2 自機の出撃初速を 10 にする

`src/mission/MissionRunner.ts` 536-541 行を差し替える。

```ts
      // 発艦の実初速。カタパルトから押し出された直後はほぼ静止で、
      // そこからエンジンが速度設定 (下の throttle) まで伸ばす。
      // 母艦・待機列の民間船と擦ったときの相対速度を下げるため、10 kps に固定する
      // （07_更なる改善 W1。従来は巡航速度そのままで出現していた）。
      speed: LAUNCH_SPEED,
      // 速度設定は従来どおり巡航値。T2-⑤ で決めた
      // 「どの難易度でも巡航速度から始める（気づかないと 100 秒失う事故を無くす）」を維持する。
      throttle: this.difficulty.id === 'easy' ? 0.5 : LAUNCH_THROTTLE,
```

ファイル上部の定数群（`LAUNCH_THROTTLE` の隣）へ次を追加する。

```ts
/**
 * 発艦時の実初速 (kps)。
 * 速度設定 (`LAUNCH_THROTTLE`) とは別で、こちらは「カタパルトから出た瞬間の速度」。
 * `DeckSequence.startLaunch()` の射出速度と同じ値を使う（出所を1つにするため export する）。
 */
export const LAUNCH_SPEED = 10;
```

### 手順 1-3 カタパルト射出速度を 10 にする

`src/app/DeckSequence.ts`

1. `import { LAUNCH_SPEED } from '../mission/MissionRunner';`
   — 循環参照になる場合（`MissionRunner` が `DeckSequence` を参照していないか確認）は、
   `src/mission/types.ts` へ `LAUNCH_SPEED` を移し、両方からそれを import する。
   **同じ値を2か所に書かない**（AI_CODING.md の「表示と実挙動は同じ出所」に準じる）。
2. 62-64 行を差し替える。

```ts
    // 発艦直後の初速。カタパルトで押し出されるが、母艦の至近で高速だと
    // 擦った瞬間に致命傷になる（質量比が上限 14 に張り付く）ため 10 kps とする
    player.vel.copy(_fwd).multiplyScalar(LAUNCH_SPEED);
    if (player.input) player.input.throttle = 0;
```

`input.throttle = 0` はそのまま（演出中は台本が 0.1 → 1 → 0.7 と動かす）。
演出が終わると `Game.applyPlayerInput()` が `InputManager.throttle`
（＝ `startMission` で spawn 時の速度設定を写した値）で上書きするので、
**巡航値へ自然に戻る**。ここで復元処理を足すと二重になるので足さない。

### 手順 1-4 影響の確認

- `src/app/game.ts:951` `this.input.throttle = player.input.throttle` は
  spawn 時の `throttle` を読むので、手順 1-1 の変更で意図どおり巡航値になる。
- チュートリアル（`src/ui/Tutorial.ts:250` 付近）は「スロットルが**上がったこと**」を
  値の変化で判定している。初期値は従来と同じなので判定は変わらない。
- お手本モード（`TutorialDemo`）は `InputManager.throttle` を基準に動くので影響なし。

# W2 — Easy では非敵対勢力との接触ダメージを 0 にする

## 現状

`src/sim/combat.ts`

- `resolveShipCollisions()`（398 行）が総当たりで重なりを見て、
  0.5 秒に1回 `applyCollisionDamage()` を呼ぶ。
- `applyCollisionDamage()`（424 行）は相対速度と質量比からダメージを出し、
  `scaleDamage()` で `playerDamageTaken` を掛ける。
- 難易度プロファイル（`src/app/settings.ts` `DIFFICULTIES`）に接触関連の項目は無い。

## あるべき姿

- 難易度 Easy のとき、**プレイヤー機と非敵対勢力（`isHostile(player, other) === false`）の接触**は
  双方のダメージ 0。爆発演出も出さない（0 ダメージなので既存の条件分岐で自然に出なくなる）。
- 押し戻しは従来どおり行う。
- 敵機との接触、AI 同士の接触、NORMAL / HARD は変えない。
- 誤射（被弾）は対象外。

## 手順

### 手順 2-1 難易度プロファイルに項目を足す

`src/app/settings.ts`

1. `DifficultyProfile` に追加する。

```ts
  /**
   * 非敵対勢力（母艦・輸送船・救難ポッド・僚機・中立艦）との接触ダメージ倍率。
   *
   * 接触ダメージは質量比 `min(14, 0.6 + 相手半径/自半径 × 1.6)` を掛けるので、
   * 母艦のような大質量に触れると 1回で 100 前後（ホーネットの hull と同値）になる。
   * 「発艦直後に母艦を擦って沈む」を「やさしい」で起こさないため、ここだけ 0 にできるようにした。
   * **プレイヤー機が当事者の接触にだけ掛かる**（AI 同士の接触・敵機との接触・誤射には掛からない）。
   * NORMAL / HARD は 1（据え置き）。
   */
  friendlyCollisionDamage: number;
```

2. 各難易度へ値を入れる。`easy: 0` / `normal: 1` / `hard: 1`。
3. 「ゲーム」タブの難易度サマリ（`src/ui/SettingsPanel.ts` の `note(...)`）に
   `味方接触ダメージ 0%` を追記する（表示と実挙動を同じ出所から作るため、
   `DIFFICULTIES[...].friendlyCollisionDamage` を読んで出す）。

### 手順 2-2 `CombatOptions` へ渡す

`src/sim/combat.ts` の `CombatOptions`（`setCombatOptions` の型）へ
`friendlyCollisionDamage: number` を追加し、既定値 1 を入れる。
呼び出し側（`src/sim/step.ts` または `src/app/game.ts` で `setCombatOptions` している箇所。
`playerDamageTaken` を渡している場所と同じ）で `difficulty().friendlyCollisionDamage` を渡す。

> 実装時に確認: `setCombatOptions` の呼び出し元を `grep -rn "setCombatOptions" src` で洗い、
> **すべての呼び出しに新項目を渡す**（型エラーで検出できるが、既定値を持たせて漏れても 1 になるようにする）。

### 手順 2-3 接触ダメージの計算へ免除を入れる

`applyCollisionDamage()`（424 行）の冒頭へ追加する。

```ts
function applyCollisionDamage(world: World, a: Entity, b: Entity, mid: Vector3): void {
  // 「やさしい」では、自機と非敵対勢力の接触を無傷にする（07_更なる改善 W2）。
  // 母艦との質量比は上限 14 に張り付くので、擦っただけで致命傷になっていた。
  // 押し戻し (separate) は呼び出し側で行うので、めり込んだままにはならない。
  if (combatOpts.friendlyCollisionDamage <= 0 && isPlayerFriendlyPair(world, a, b)) return;
  ...
}

/** 自機が当事者で、相手が非敵対勢力の接触か。 */
function isPlayerFriendlyPair(world: World, a: Entity, b: Entity): boolean {
  const player = a.id === world.playerId ? a : b.id === world.playerId ? b : undefined;
  if (!player) return false;
  const other = player === a ? b : a;
  return !isHostile(player.faction, other.faction);
}
```

`isHostile` は `src/content/factions.ts` から import する（`combat.ts` は未 import なら追加）。

**倍率としても効かせる**: 0 以外の値を将来入れられるように、`return` ではなく
倍率として掛ける形も検討したが、**0 のときの「爆発演出も出さない」を素直に書けるため
早期 return を採る**。0 < x < 1 が必要になったら
`base *= friendlyCollisionDamage` へ書き換える（その時点で `<= 0` の早期 return も残す）。

### 手順 2-4 クールダウンの扱い

`resolveShipCollisions()`（409-414 行）は `applyCollisionDamage()` の前に
両者の `collisionCooldown` を 0.5 秒へセットしている。**この順序は変えない**。
免除された接触でもクールダウンは進むが、ダメージが 0 なので観測できる違いは無く、
毎フレーム `isPlayerFriendlyPair()` を呼ぶより安い。
