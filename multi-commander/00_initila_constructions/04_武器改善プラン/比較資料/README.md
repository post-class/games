# 武器別・改善前後比較資料

このフォルダには、現行の主砲4種・ミサイル4種と、追加した主砲2種・ミサイル2種について、武器ごとの比較資料を置く。

- `01_before-audio.wav`: Git のベースライン相当の比較用音声
- `02_after-audio.wav`: 改善後候補Aの比較用音声（互換用の単体リンク）
- `01_before-graphic.svg`: ベースラインの弾体・航跡・起爆表現の概要
- `02_after-graphic.svg`: 現在の弾体・航跡・起爆表現の概要
- `03_after-1/2/3-graphic.svg`: 選択用の改善後グラフィック候補A/B/C
- `03_after-1/2/3-audio.wav`: 選択用の改善後音声候補A/B/C
- 各武器の `README.md`: 実装箇所、差分、確認方法

音声はゲーム内で直接読み込むファイルではない。ゲーム本体は引き続き Web Audio 合成を使用しており、比較用 WAV は `AudioManager` の発振器・フィルター・エンベロープのプロファイルを聴き比べるためのプレビューである。グラフィックは実行時の Three.js procedural VFX を武器種別ごとに確認できるようにしたベクター比較カードである。

## 結論

旧8種は今回の拡張で既存の発射音・弾体表現を置き換えていないため、`before` と `after` は実質的に同一である。音が変わっていないように感じるのはこのためで、今回明確に追加された差分は新4種の音声・弾体・航跡・爆発表現になる。

新4種は以前の実装が存在しないため、`before` は「未実装」として記録し、`after` のみ実体ファイルを置いている。

各武器の `03_after-1/2/3-*` が選択用の3候補である。候補Aは明瞭な基準音。候補Bは機械作動・金属アタック・近距離反射を重ねた実機感重視。候補Cは推進/燃焼ノイズ・低域の圧力・長めの空間余韻を重ねた実機感重視。今回、後半2候補（B/C）の24ファイルを作り替えた。これらは選択前の比較用で、ゲーム本体にはまだ反映していない。

武器一覧は [00_比較一覧.md](./00_比較一覧.md) を参照。

ブラウザで比較する場合は [比較ビューアー](./index.html) を開く。各武器のラジオボタンで候補を切り替え、全武器または個別武器の選択値をクリップボードへコピーできる。

改善後候補のラジオボタンを選択すると、右側の音声が自動的に停止・切り替え・再生される。ブラウザの自動再生制限により、ページ読み込み直後には再生せず、ユーザー操作を起点に再生する。

採用決定: 全武器で候補C（`03_after-3-audio.wav`）を採用した。ゲーム本体では `public/audio/weapons/*-after3.wav` として再生し、主砲発射音・ミサイル発射音に接続している。
