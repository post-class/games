# 武器アップグレード設計・基準記録

更新日: 2026-08-06

## 個性設計表

主砲は、ダメージ値だけではなく、弾速・連射・消費・弾体形状・音色・命中時の役割を同時に変える。
ミサイルは、ロック条件・誘導・フレア耐性・アーム時間・爆発規模を変える。

| 武器 | 役割 / 適正距離 | 発射方式・弾速 | 連射 / 消費 | 命中の特徴 | 表示・音の識別 |
|---|---|---:|---:|---|---|
| レーザー砲 | 高速な近〜中距離の継続火力 | needle beam / 1600 | 0.20 s / 3 | シールドにはやや弱い。白熱と細いスパーク | 赤い細長い光弾、高域の短音 |
| マスドライバー | 装甲を削る中距離の重い一撃 | heavy slug / 1250 | 0.32 s / 5 | 強い反動、装甲片と低域衝撃 | 琥珀色の弾体、金属的な低音 |
| ニュートロンガン | シールド破壊用の中距離砲 | ring plasma / 1050 | 0.50 s / 9 | シールド倍率 1.45、波紋と放電 | 青白い太い弾体、唸り+電気音 |
| パーティクルキャノン | 回避中の敵を追う遠距離速射 | scatter particle / 1900 | 0.22 s / 4 | 粒子の散開と多段の小さな火花 | 紫の分裂光点、細かい連射音 |
| ダムファイア | 近距離の読み合い。無誘導 | smoke / 700 | 即時 / 弾数 | ロック不要、アーム後に直進 | 白い機体、濃い煙、低い発射音 |
| ヒートシーカー | 戦闘機を追う短ロック | ion / 620 / 熱追尾 | 1.1 s / 弾数 | フレアに弱い。AB熱源で追尾が強まる | 橙色、細いイオン尾、上昇音 |
| イメージレコグニション | 高機動目標への長寿命誘導 | spark / 600 / aspect | 2.2 s / 弾数 | 強誘導・フレア耐性、回避は可能 | 水色、火花の航跡、二段ロック音 |
| 対艦魚雷 | 艦艇・輸送艦を狙う重量弾 | heavy-smoke / 380 / aspect | 5.0 s / 弾数 | 0.8 sアーム、長ロック、広範囲の大型爆発 | 黄土色の大型弾体、低域の長い爆発音 |

## 共通イベント契約

- 発射: `weaponFired`。`weaponId`、プロファイル、反動を含む。
- 命中: `shieldHit` / `armorHit`。武器ID、ダメージ種別、距離、命中面、クリティカル相当を任意payloadで含む。
- 爆発: `explosion`。中心、半径、武器ID、起爆演出、巻き込んだ対象数を含む。
- 撃破: `destroyed`。既存の撃墜理由・撃墜数・リプレイ仕様を維持する。
- 発射不可: `weaponDenied`。エネルギー不足、砲損傷、弾切れ、ロック未完了、対象不適合を通知する。

イベントの追加項目は任意なので、古いセーブデータや障害物由来の既存イベントを購読する描画・音声側でも欠損時に安全な既定値へ戻る。

## 現状基準

アップグレード前の基準値は、変更前の `src/content/weapons.ts` に定義されていた主砲4種の数値と、既存テストが保証していた仕様を記録したもの。

| 項目 | アップグレード前の基準 |
|---|---|
| 主砲 | レーザー 1600 / 0.20 s / 3、マスドライバー 1250 / 0.32 s / 5、ニュートロン 1050 / 0.50 s / 9、パーティクル 1900 / 0.22 s / 4 |
| ミサイル | DF 700、HS 620、IR 600、魚雷 380。ロック時間は 0 / 1.1 / 2.2 / 5.0 s |
| 保証された仕様 | 弾道スイープ、シールド→装甲→ハル、爆風減衰、フレア、アーム時間、弾数、ロック、部位損傷、リプレイ |
| 自動検証 | `npm run typecheck`、`npm test`、`npm run build` |
| 手動検証 | README の「手動確認」に、4主砲・4ミサイルを近/中/遠距離で試す手順を記録 |
| 画面基準 | 1280×720 の訓練中に HUD スクリーンショットを `.tmp/weapon-upgrade-hud-720p.png` として保存。右 VDU は `clientHeight=231 / scrollHeight=231` で情報が切れないことを確認 |
| 描画基準 | 同じ訓練画面で `requestAnimationFrame` を60回採取: 平均 8.30 ms / 120.5 fps / p95 9.10 ms。大量爆発時はVFX上限（スプライト512、火球96、軌跡80）を適用 |

発射間隔・エネルギー消費・弾数消費・ロック条件は `tests/weapon-upgrade.test.ts` と既存の戦闘テストで固定する。
描画負荷は、VFXプールのスプライト512個・火球96個、軌跡の1フレーム予算80個、遠距離敵メッシュ24体という上限を基準とする。
