# 武器グレードアップ タスクリスト

## 目的

現在の武器は、機能としてはレーザー・マスドライバー・ニュートロンガン・パーティクルキャノン、各種ミサイルまで揃っている。一方で、発射物の見た目・発射から命中までの手応え・武器ごとの音色・武器を使い分ける理由がまだ弱い。

武器ごとに「見た瞬間に種類が分かる」「撃った瞬間に重さや性質が分かる」「命中した結果が分かる」状態を目標にする。

## 完了条件

- [x] 主砲4種とミサイル4種について、見た目・音・挙動の識別性がある
- [x] 発射、飛翔、命中、撃破の各段階でフィードバックが途切れない
- [x] 武器の強化で照準の見やすさが悪化しない。HUD・ターゲット視認性を維持する
- [x] 戦闘中のエフェクト数が増えても、通常の交戦で描画負荷が許容範囲に収まる
- [x] 既存のダメージ、弾数、ロック、部位損傷、リプレイの仕様を壊さない
- [x] `npm run typecheck`、`npm test`、`npm run build` が通る

## 推奨する実装順

1. P0-1 で武器の個性を決める
2. P1-1 でデータの受け皿を作る
3. P1-2〜P1-4 で挙動とイベントを固める
4. P2-1〜P2-4 で発射物と命中演出を作る
5. P3-1〜P3-3 で音を合わせる
6. Phase 4 でHUDとチュートリアルを整える
7. Phase 5 で自動テスト、手動プレイ、性能確認を行う
