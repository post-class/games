01

最初の5分

初回は、すべてを覚える必要はありません。次の順番だけで敵機を倒せます。

1

速度を作る

5 でスロットルを50%にします。速度が出ると、接近・離脱・旋回のすべてが安定します。

2

最寄りの敵を選ぶ

R で最寄りの敵、Y で正面にいる敵をターゲットします。右側の TARGET 欄に敵名と距離が出れば準備完了です。

3

黄色い点線の丸へ機首を向ける

画面中央の照準ではなく、敵の前方に出る黄色い点線の丸が偏差照準です。そこへ敵を重ねると、移動中の敵にも当てやすくなります。

4

主砲を保持する

Space を押し続けます。HUD の右上に「命中確認 — シールド」「装甲」「船体」が出れば、ダメージが通っています。

5

撃破後に次の敵へ

右側の敵情報が消えたら R を押して次の敵を選択します。全戦闘目標を片付けたら A で次の Nav へ進みます。

まず試す設定：ポーズ中の「設定」→「操作」→旋回補助をONにすると、ターゲット方向へ微調整が入り、敵を視界に捉えやすくなります。

03

HUD の見方

画面下の3つのパネルは「自分」「飛行」「敵と武装」を表します。戦闘中は数値の変化を見て判断します。

SELF / SYSTEMSSHIELD、ARMOR、HULL が自機の生存状態。GUN PWR は砲とシールドで共有するエネルギーです。
SHIELDS / ARMOR緑のシールド表示と HULL の割合を確認。シールドが戻らないときは被弾直後か、エネルギー不足です。
RADAR赤が敵、青が味方、金がエース、白がミサイル。中心が機首方向、外周が後方です。
TARGET / NAV [V]ターゲット名、種類、距離、接近／離脱、シールド、船体を表示。敵が消えたら次の目標を選び直します。
WEAPONS [V]選択中の副兵装、残弾、エネルギー、発射可否、ロック状態を表示。V で切替。
右上の戦闘ログ命中確認、ロック完了、ミサイル命中、撃破などの短い通知を表示します。
ロック表示：「ロック中」は進行率が増えている状態、「ロック完了」で Enter が有効です。距離が遠い、または機首から外れると進行が止まり、ロックが解除されます。
04

戦闘のコツ

狙い方

  • 敵の機体そのものではなく、敵の進行方向に出る黄色い偏差照準へ主砲を撃つ。
  • 敵が横切るときは、無理に追い続けず、旋回して次の交差点で迎え撃つ。
  • マウス操縦は画面中央付近をニュートラルにして、短く動かして微調整する。
  • 敵が近いときはスロットルを少し絞ると旋回しやすくなります。遠距離では速度を維持します。

主砲の使い方

  • 主砲はエネルギーを消費します。撃ち続けて GUN PWR が減ると、発射やシールド回復に影響します。
  • 敵のシールドが厚いときは、シールド倍率の高い武器や副兵装を使います。
  • 主砲の詳細なダメージ、弾速、射程、用途は武器カタログで確認できます。
  • 弾が当たらないときは、照準位置・距離・敵との角度を見直し、近づいてから再度撃ちます。

守り方

  • 赤いロックオン警告やミサイル警告が出たら、まず機首を変え、必要なら G でフレア。
  • シールドが減ったら撃ち合いを続けず、敵の正面から外れて再生時間を作る。
  • HULL が減ると部位損傷が発生します。砲やエンジンが損傷したら無理に深追いしません。
  • 自機が危険なときは C → 4 で僚機に支援を要請できます。

僚機への指示

C で通信を開き、数字を押します。

1 編隊→2 私の目標を攻撃→3 散開して交戦→4 支援

敵の数が多いときは 2 で自分のターゲットを共有し、撃ち漏らしを減らします。指示後も自分は別の敵を選べます。

05

ミサイル運用

ダムファイア

ロック不要で即時発射。敵が近く、進行方向が読めるときに使います。撃つ前に敵へ機首を合わせる必要があります。

無誘導即時発射

誘導ミサイル

敵を機首正面に捉え続け、WEAPONS ページで「ロック完了」を確認してから Enter。射程外や急旋回ではロックが外れます。

要ロック戦闘機向け

対艦魚雷

大型目標専用。長いロック時間が必要です。戦闘機を選んでいると発射できないため、艦艇をターゲットしてください。

大型目標長時間ロック
基本手順： X で弾種を選ぶ → R または T で目標を選ぶ → 機首を向ける → WEAPONS のロックメーターを確認 → Enter。発射不可の理由は HUD に表示されます。
フレア対策：ヒートシーカーはフレアに弱い一方、画像認識系の誘導弾はフレア耐性が高めです。敵がフレアを放ったからといって、すべてのミサイルが無効になるわけではありません。
06

任務と帰投

敵を倒すことだけが任務ではありません。画面右上の目標リストを常に確認してください。

ブリーフィング→出撃→Nav到達→戦闘／護衛→帰投→デブリーフィング

Nav を進める

現在の戦闘目標を片付けたら A。敵が近い、小惑星帯・機雷原にいる、または到達済みの場合はオートパイロットが拒否されます。警告が出たら場所を少し移動して再入力します。

戦闘後に帰投する

目標達成後は A で次の Nav、最後の Nav から母艦へ向かいます。必須戦闘目標を達成していれば、残敵がいても戦域離脱できる場合があります。

護衛任務

敵の撃破数より護衛対象の生存が優先です。護衛対象の近くで敵を引き離し、危険になったら C で支援を呼びます。

脱出する

Alt+E を2回で脱出。パイロットは助かりますが、機体喪失として任務は失敗します。最後の手段として使ってください。

失敗しても終わりではありません。任務失敗時は戦況が悪化した分岐ルートへ進みます。そこで勝利すれば本線へ復帰できます。
07

困ったとき

敵に弾が当たらない

まず R でターゲットし、黄色い偏差照準へ向けます。距離が遠すぎる場合は接近し、敵が横切る瞬間に主砲を保持してください。設定の旋回補助も有効です。

ミサイルが撃てない

V で WEAPONS を開き、発射不可の理由を確認します。主な原因はロック未完了、弾切れ、対象種別違いです。ダムファイアはロック不要です。

機首が勝手に動く

メニューから戻った直後は、カーソルを画面中央付近へ戻してマウス操縦を再アームします。不要なら M でマウス操縦をOFFにして矢印キーを使います。

オートパイロットが動かない

敵が近い、障害物が近い、すでに Nav に到達している、のいずれかです。HUD の警告を読み、敵を引き離すか、小惑星帯・機雷原から離れて再度 A を押します。

機体がすぐ壊れる

やさしい難易度では敵の攻撃と同時攻撃数が抑えられています。敵を正面に置き続けず、シールドが減ったら距離を取り、フレアと僚機を使います。

練習したい

タイトルの「チュートリアル」から簡易／詳細訓練を選べます。訓練はキャンペーンの戦果、補給、名簿、戦況を変更しません。

おすすめの練習順： R でターゲット → Space で主砲 → X で副兵装 → ロックを待って Enter → C → 2 → A。この一連の流れを覚えれば、最初の哨戒任務は十分に戦えます。

Multi-Commander ユーザーガイド。ゲーム内の設定でキー割り当てや難易度を変更した場合は、ゲーム内表示がこのガイドより優先されます。
