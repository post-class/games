# Multi-Commander E2E テストケース（2026-08-06）

対象 URL: `http://127.0.0.1:4173/`（Vite 開発サーバー）  
実施方式: Playwright headless MCP。画面の状態確認はアクセシビリティスナップショット、見た目の確認は全画面スクリーンショットで行う。

証跡は同ディレクトリ配下のケース別サブディレクトリに保存する。

## 共通確認

- [x] fatal error 表示、コンソール error、未読込アセットによる崩れがない
- [x] 各画面でスクリーンショット（`fullPage: true`）を保存する
- [x] 各画面の有効な全メニュー項目をクリックで一度ずつ確認する
- [x] メニュー画面では `ArrowUp` / `ArrowDown` / `W` / `S` / `Enter` / `Space` / `Escape` を確認する（無効項目は選択されないこと）
- [ ] 戦闘画面では README 記載のキーボード、マウス、ホイール操作を個別に実施し、各操作の前後で HUD または状態が変化することを確認する
- [ ] 入力ケースごとに初期状態、実イベント、期待値、画面確認、失敗時証跡を記録する

## E2E-01 タイトル・ヘルプ・設定

1. タイトル画面を開き、全画面キャプチャを取得する。
2. 「新規戦役モードを切替」を押し、CANON / EXPANDED が切り替わることを確認する。
3. 「操作説明」→「音楽クレジット」→「戻る」→「戻る」で各画面を確認する。
4. 「設定」を開き、設定項目（難易度、マウス操縦、ゲームパッド関連、音量）を操作し、戻る。
5. タイトルメニューで矢印キー、W/S、Enter/Space、Escape を使って遷移できることを確認する。

期待結果: タイトル、操作説明、音楽クレジット、設定が表示され、戻る操作で直前の親画面へ戻る。画面外への遷移や fatal error がない。

## E2E-02 母艦ハブの全画面・全ボタン

1. 「新しい戦役を始める」から母艦ハブへ進み、全画面キャプチャを取得する。
2. 以下を順番に開き、画面キャプチャ後に戻る。
   - ブリーフィング室
   - 格納庫
   - 酒場（隊員との会話、噂を聞く）
   - 自室（保存・ロード、各スロット、戻る）
   - キルボード
   - 戦況マップ
   - 訓練室（種目、敵機数、敵技量、開始、戻る）
   - 統計
   - 設定
3. ハブ内の「出撃」ボタンがブリーフィングへ到達することを確認する。
4. 全ての戻る／キャンセル操作をクリックと Escape の両方で確認する。

期待結果: 各パネルが対応する内容を表示し、状態変更（会話、保存、モード等）が画面更新に反映される。無効なロードスロットは選択できない。

## E2E-03 ブリーフィング・格納庫・出撃前操作

1. ブリーフィングの任務目標、飛行計画、機体、僚機を確認しキャプチャを取得する。
2. 「格納庫へ戻る」「操作案内なしで出撃」「出撃（操作案内あり）」を確認する。
3. 格納庫で機体変更、僚機変更、単独出撃、戻るを確認する。
4. キーボードメニュー操作（矢印/W/S、Enter/Space/Escape）を確認する。

期待結果: ブリーフィングの内容が空にならず、格納庫の選択内容が出撃表示へ反映される。

## E2E-04 戦闘画面の操作・ポーズ・通信・航法

訓練室の `quiet`（敵なし）または通常出撃で戦闘画面へ入り、全画面キャプチャを取得する。

- [x] `ArrowUp/Down/Left/Right`、`Q/E` で操縦・ロール
- [x] `]` / `[`、`+` / `-`、数字 `0〜9`、`` ` ``、Backspace、ホイールでスロットル
- [x] Tab 押下中のアフターバーナー、`M` のマウス操縦切替、`F` の視点切替
- [x] Space/左クリックの主砲、Enter/右クリックのミサイル、`X` の副兵装切替、`G` のフレア
- [x] `T/R/Y` のターゲット操作、`D` の被害表示、`A` のオートパイロット、`N` の航法マップ
- [x] `C` の通信メニューと数字 `1〜4` の全指示
- [x] Escapeでポーズ画面を表示し、全ボタンがviewport内で視覚的に表示されることを確認
- [x] Escapeでポーズ、再開、設定、操作方法、リプレイ、やり直し、タイトルへ戻る導線を確認
- [x] マウス移動で照準、左／右クリック、右クリックのコンテキストメニュー抑止

期待結果: HUD の値・表示・ログ・画面遷移が操作に対応し、ポーズ中に戦闘入力が進行しない。各画面のキャプチャを保存する。

## E2E-05 シナリオ（訓練完了 → デブリーフ → 再入場）

1. 訓練室で `quiet` を選択して開始する。
2. `A` を押して航法・帰投を実行し、任務終了まで待つ。
3. 訓練終了画面の全ボタン（リプレイ、JSON保存、訓練室へ戻る、艦内へ戻る）を確認する。リプレイが無効な場合は無効状態も記録する。
4. 訓練室／母艦へ戻り、タイトルへ戻る。

期待結果: キャンペーンの資源・名簿を変更せず、デブリーフから訓練室または母艦へ戻れる。ダウンロード操作でエラーを出さない。

## E2E-06 入力契約（単発キー・ホイール・実 DOM 経路）

quiet 訓練を開始し、発艦演出が終わるまで待ってから実施する。入力対象は `#view` canvas とし、HUD の `THROTTLE` 表示および読み取り専用の `window.__mc.game.input.throttle` を前後で記録する。

### 事前条件

- `window.__mc.game.deck.phase === 'none'` になるまで待機する。
- `window.__mc.game.input.throttle` を画面操作で `0%` にする（数字 `0` を使用する）。状態の直接代入は禁止する。
- `.mc-tutorial` が表示されている場合は、入力前後のステップ番号も記録する。
- `#overlay` の computed style が `pointer-events: none`、`#view` が実際の入力対象であることを確認する。

### 入力ごとの判定表

| ID | 実イベント | 初期値 | 期待する直後の値 | 画面上の確認 |
|---|---|---:|---:|---|
| I-01 | `page.keyboard.press(']')`（単発） | 0% | 10% | HUD が 10% になる |
| I-02 | `page.keyboard.press('[')`（単発） | 10% | 0% | HUD が 0% になる |
| I-03 | canvas 上で `page.mouse.wheel(0, -100)` | 0% | 10% | HUD が 10%、ページスクロールなし |
| I-04 | canvas 上で `page.mouse.wheel(0, 100)` | 10% | 0% | HUD が 0%、ページスクロールなし |
| I-05 | `page.keyboard.press('5')` | 0% | 50% | HUD が 50% になる |
| I-06 | `page.keyboard.down(']')`、250ms以上待機、`up(']')` | 0% | 10%より大きい | 押下時間に応じて HUD が連続増加する |

### 追加確認

1. I-01〜I-06 は別々に実行し、各操作の前後値を同じ証跡ファイルに記録する。最終値だけの確認は不合格とする。
2. I-01〜I-04 は、ブラウザ上の入力イベントが canvas に届くこと、`wheel` の `defaultPrevented` が true になること、`scrollX` / `scrollY` が変化しないことを確認する。
3. I-01〜I-06 の操作中にチュートリアルが表示されている場合、スロットル条件達成後に `訓練 2 / 6` へ進むことを確認する。
4. `contextmenu` が表示されないこと、コンソール error が増えないことを確認する。
5. 期待値が変化しなかった場合は、操作実施済みでも FAIL とし、操作前後スクリーンショット、アクセシビリティスナップショット、console/network 記録を保存する。

期待結果: 各入力が他の入力の結果に依存せず、表の期待値へ変化する。透明な overlay によってホイール入力が阻害されず、発艦演出中の値上書きを実入力の不具合として誤判定しない。

### 修正・再テスト

初回実施でアプリの不具合は検出されなかったため、アプリコードの修正はなし。証跡の不足分（ハブの自室、保存／ロード、キルボード、戦況マップ、訓練、統計）は追加確認し、全ケースの結果を更新した。最終確認としてタイトル起動、母艦遷移、quiet 訓練画面を並列再実施し、再テストも PASS とした。

追加網羅テスト（キャンペーン終端、EXPANDED動的作戦、全スロット、全設定、戦闘エッジ、互換入力）は [FULL_COVERAGE.md](./FULL_COVERAGE.md) に記録し、Playwrightで実施した範囲は完了した。
