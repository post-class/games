## 実測値

### 発艦の初速（フレームごと）

```
t=0: 10.0 KPS / 速度設定 0（カタパルト保持）
t=1: 10.0 KPS / 速度設定 0.5
t=2: 34.3 KPS
t=5: 39.1 KPS
…（発艦演出 3.4 秒の後）200 KPS = 最高速 400 × 速度設定 50%
```

### Easy の母艦接触（`tag: 'homebase'`、半径 225）

```
接触前: hull 100 / armor.front 25 / shield.front 42 / 距離 12598
接触後: hull 100 / armor.front 25 / shield.front 42 / 距離 504（最小接触距離 240）
→ 無傷。押し戻しは働いている
friendlyCollisionDamage を 1 に戻して同じ接触: hull 100 → 0
```

### コクピット表示 5段階（実 UI から一巡）

| 表示 | 骨組み | ガラス | 計器盤 | 全体 |
|---|---|---|---|---|
| 風防ぜんぶ | ○ | ○ | ○ | ○ |
| ガラスのみ | × | ○ | ○ | ○ |
| 骨組みのみ | ○ | × | ○ | ○ |
| 計器盤のみ | × | × | ○ | ○ |
| 非表示 | × | × | × | × |

### 新しいキー操作

```
+ 単押し     : 速度設定 0.5 → 0.6
- 単押し ×2  : 0.6 → 0.4
] 単押し     : 0.4 → 0.5（旧キーも有効）
I            : 射線上の僚機を掴む（targetId 一致）／該当なしは「照準下に目標なし」
;            : 「速度同期 277 KPS（69%）」、速度設定 0.5 → 0.691
L            : lockArmed = true
Alt+B/H/F/A  : break-and-attack / help-me / form / attack-my-target（メニューは開かない）
A（修飾なし）: 従来どおりオートパイロット（第1章の開始位置は小惑星帯なので
               「障害物接近、オートパイロット解除」が正しく出る）
/ 押下中     : 後方視点（照準非表示・計器盤は継続）
```

## 未確認・注意

- **難易度「ふつう」での母艦接触は、実 UI 経由では未確認**（免除を外した状態での即死は上記のとおり確認済み。
  Normal / Hard の数値は `tests/ut/w2-friendly-collision.test.ts` が固定している）。
- 音が実際に鳴っているかは自動判定できないため、BGM の切替は
  **保存データへの反映と `MusicDirector` の状態**で確認した（曲の差し替え・無音の選択）。
- 開発中に確認スクリプトから `/src/app/settings.ts` を動的 import すると**別インスタンス**になり、
  設定変更がゲームへ届かない。設定の確認は必ず**実 UI（設定画面のボタン）経由**で行う。
