# E2E-14 十章キャンペーン（THE VEIL FRONT）

## 目的

新設定「THE VEIL FRONT」の十章キャンペーン（`veil` モード）が、実ブラウザで通しでプレイできることを確認する。
特に、**撃墜数ではなく「誰を帰したか」で進行が変わる**という仕様が、実際の画面と状態に反映されていることを見る。

## 共通条件

- 対象 URL はテスト実行時の Vite URL とする（確認時は `http://localhost:5199/`）。
- ブラウザ確認は chrome-devtools MCP を使う。**同時に開くブラウザは1つ**。
- 画面サイズは **1280×720** と **844×390** の両方で確認する。
- 各ステップで次を記録する。
  - `document.documentElement` の `scrollWidth` / `clientWidth` / `scrollHeight` / `clientHeight`
  - 対象要素の `getBoundingClientRect()`（左右がビューポート内に収まっているか）
  - `list_console_messages` の `error` / `warn` 件数
  - スクリーンショットと accessibility snapshot
- 入力は**実キー入力・実クリック**で行う。`dispatchEvent` だけで PASS にしない。
- 保存データを直接書き換える検証は「補助検証」と明記し、入力経路の確認には使わない。

## 実施状況の凡例

- **実施済み**: 2026-08-09 に chrome-devtools MCP で確認した。証跡あり。
- **補助検証**: 保存データを用意して画面表示だけを確認した。入力経路は別ケースで確認済み。
- **未実施**: まだ確認していない。実施済みと混同しない。
