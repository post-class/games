# 02 ビジョンと設計の柱

## 0. 一行ビジョン

> **「ブラウザを開いた瞬間、映画の宇宙戦に放り込まれる。仲間の名前を覚え、その生死に胸が痛む、手に汗握るドッグファイト。」**

初代要望（`00_initila_constructions/00_youbou.md`）は明快だった——**「ウィングコマンダーと同等か、それ以上に面白いゲーム」**。本計画のゴールはこの一文を、ブラウザ上のTypeScript製ゲームとして本気で満たすことにある。

---

## 1. ウィングコマンダーの“魂”を分解する

「面白かった」を印象論で終わらせないため、原典の魅力を要素に分解し、本作でどう再現するかを対応づける。

| WCの魂 | 何が良かったか | 本作での再現方針（対応フェーズ） |
|---|---|---|
| **シネマティックな宇宙** | 光る宇宙・爆発・迫るキャピタルシップ。当時の“実写級”演出 | ブルーム/トーンマッピング/星雲背景/多層爆発（P1・P2） |
| **反応するBGM** | 戦況で曲が切り替わり、緊張と高揚を煽る動的スコア | 脅威度駆動の適応型BGM（P3） |
| **手に馴染むドッグファイト** | 偏差射撃、アフターバーナー、僚機への指示 | 既存の飛行/リード/僚機指令を、手触り(P2)と武装多様性(P5)で拡張 |
| **仲間と物語** | 名前のある僚機、その戦死、司令室や酒場の会話 | パイロット名簿・パーマデス・ミッション間シーン（P7） |
| **勝敗で変わる戦線** | 負けても物語が続き、別ルートへ分岐する | 分岐キャンペーン（P6）＋物語フラグ（P7） |
| **昇進と勲章** | 撃墜数が階級・勲章・授与式で報われる | 勲章/階級/授与シーン（P7） |

**「同等以上」の勝ち筋:** 原典の魂を押さえた上で、本作は *ブラウザで即プレイ・インストール不要* という現代的アクセシビリティで上回る。重い操作を要求せず、キーボードだけで映画的な空戦に入れることを強みにする。

---

## 2. 設計の5本柱（North Star）

すべての実装判断は、この5本柱に照らして「柱を強くするか」で決める。迷ったら柱に戻る。

### 柱1 — 映画のような宇宙（Cinematic）
どのフレームを切り取ってもポスターになる画作り。光・色・スケール感で「本物の宇宙戦」を感じさせる。
*基準:* 静止画1枚で「これはチープではない」と即断される。 → 主にP1/P2/P4。

### 柱2 — 手に残る戦闘（Visceral）
引き金を引く・当てる・落とす、その一つ一つに重みと快感。入力から演出までの反応が速く、気持ちいい。
*基準:* 1機撃墜しただけで「もう1機やりたい」と思える手応え。 → 主にP2/P3/P5。

### 柱3 — 生きた戦場と仲間（Alive）
戦場は無機質な的の集合ではない。名前のある僚機、無線の声、迫るキャピタルシップ、展開する増援。世界が“動いている”。
*基準:* プレイヤーが特定の僚機を「守りたい」と思う。 → 主にP3/P4/P6/P7。

### 柱4 — 選択が響く物語（Consequential）
勝っても負けても物語は続き、選択と戦果が戦線・仲間の生死・エンディングに影響する。やり直しではなく“結果”がある。
*基準:* 「あの時こうしていれば」とプレイヤーが振り返る。 → 主にP6/P7。

### 柱5 — すぐ遊べて奥が深い（Accessible yet Deep）
起動30秒で空戦に入れる導線と、キーボードだけの直感操作。同時に、武装選択・機動・難易度で上達の余地がある。
*基準:* 初見でも飛べる。しかし熟練で明確に強くなれる。 → 全フェーズ横断（特にP5/P8）。

## 3. 体験の“縦の目標像”（Vertical Slice）

計画完遂後に実現していたい、1回のプレイ体験の理想像：

1. **起動** — タイトルにブルームの効いた母艦と星雲。BGMが静かに流れる。
2. **ブリーフィング室** — 指揮官と僚機（名前と顔がある）が今回の作戦を語る。僚機の一人は前回の戦いを覚えている。プレイヤーは進撃ルートを選ぶ。
3. **出撃** — コックピット後方視点。アフターバーナーでFOVが開き、エンジン音が唸る。
4. **交戦** — 敵編隊を捕捉した瞬間、BGMが戦闘レイヤーへ切り替わる。偏差射撃で1機、被弾で画面が揺れ赤く滲む。ミサイル警報が鳴りチャフを撒く。
5. **山場** — 敵キャピタルシップが出現。僚機に「各自交戦」を指示し、砲塔サブシステムを潰していく。
6. **撃墜の瞬間** — トドメの一撃でヒットストップ＋シネマティックカメラ、爆発のデブリが散る。
7. **デブリーフ** — 撃墜数が集計され、階級が上がる。だが僚機の一人が還らなかった——名簿に戦死が刻まれ、次の物語に影を落とす。

この7ステップのどこにも「安っぽさ」が無い状態が、本計画の合格ラインである。

---

## 4. スコープの原則（やらないことを決める）

「素晴らしい」を薄く広げて破綻させないため、初期の非目標を明示する。

- **物理シムの過度なリアル化はしない。** 既存のWC方式アーケード飛行＋ニュートン切替を核に据える。手触り優先。
- **オンライン必須にしない。** まずは単人称キャンペーンを完成させる。対戦/協力はP8のストレッチ。
- **重量級アセットに依存しない。** ブラウザ即プレイのため、GLTFは最適化前提。読み込みで待たせない。
- **購買型経済（課金/通貨）を核にしない。** 進行は「固定進行＋アンロック」を推奨（根拠は [`07`](./07_技術仕様_メタ進行と物語.md)）。
- **既存の良い骨格を壊す全面書き換えはしない。** ECS/データ駆動/イベントバスの上に積む（根拠は [`01`](./01_現状診断.md)）。
