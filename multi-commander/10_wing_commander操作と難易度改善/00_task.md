# Wing Commander型操作と難易度改善 — タスク一覧

## 1. 目的

現行版は機能量より先に、初見プレイヤーが「飛べない・狙えない・何をすればよいか分からない」ことで難しく感じる状態を解消する。

- Wing Commander型のキーボード＋マウス操作を、メニューから戦闘まで一貫して使えるようにする。
- `やさしい` を単なる耐久倍率ではなく、操縦・照準・索敵・進行を助けるモードにする。
- 初回プレイで説明書を読まなくても、10分以内に出撃して1機撃墜できるようにする。
- 現在の戦闘、ミッション、ロードアウト、セーブを壊さず、上級者向け機能は設定から利用可能にする。

## 2. 現状診断と改善方針

| 優先度 | 現状の問題 | 改善方針 |
|---|---|---|
| 最優先 | `MouseFlightStick` は存在するが、`InputManager` で常時無効かつ `mousemove` 未接続 | マウスを正式な既定入力にし、移動・主砲・ミサイルをマウスだけでも操作可能にする |
| 最優先 | 設定は難易度3択のみ。操作設定やゲーム中の変更手段がない | Wing Commanderプリセット、感度、Y反転、照準補助、音量等を保存可能にする |
| 最優先 | メニューとロードアウトがキーボード専用 | クリック、ホバー、キーボードフォーカスを同じUIで扱う |
| 高 | Easyは敵/自機の数値倍率だけで、照準・索敵・空間認知を助けない | 自動ターゲット、照準アシスト、敵同時攻撃数、ウェーブ間隔をEasyプロファイル化する |
| 高 | 出撃時スロットル0%、多数のキー、誤操作しやすいNewton切替 | 初速付与、状況ヒント、WC飛行固定を既定にし、高度な機能を設定へ移す |
| 高 | 初回から通常ミッションへ入り、失敗は最初から再挑戦 | 短い訓練とチェックポイントを追加する |
| 中 | HUDは情報量が多いが、次に行う操作の案内が弱い | 状況に応じた1件だけの操作ヒントと目標誘導を追加する |
| 後続 | 分岐、人物、実アセットなどはまだWing Commanderに及ばない | 操作改善完了後のバックログとして残し、今回の完了を妨げない |

詳細仕様は [`01_操作と設定仕様.md`](./01_操作と設定仕様.md)、Easyと検証基準は [`02_Easyと検証仕様.md`](./02_Easyと検証仕様.md) を参照する。

## 3. 実装ルール

- タスクは原則として番号順に実施する。`P0`〜`P5` を今回の必須範囲、`P6` を次期バックログとする。
- 各親チェックボックスは、その配下の実装・テスト・文書更新がすべて完了したときだけ `[x]` にする。
- 入力値、設定値、難易度補正をUIやシステムへ直書きしない。型付き設定を単一情報源にする。
- 既存localStorageを読み込めるようにし、移行失敗時も起動不能にしない。
- UI表示中は戦闘入力を停止し、画面遷移時に押下状態を必ずクリアする。
- 既存の30ユニットテストを維持し、新規ロジックにはテストを追加する。
- 一時ファイルは `.tmp/` に置く。

- [ ] Newton飛行は誤操作で有効にならず、上級者は設定から利用できる。
- [ ] 設定はリロード後も保持され、旧難易度設定と既存キャンペーンセーブを失わない。
