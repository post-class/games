# Easyと検証仕様

## 1. Easyの設計目的

Easyは「敵の数字が小さい」だけでなく、プレイヤーが敵を見つけ、追い、狙い、撃墜し、失敗から学べるモードとする。主操作を奪う自動戦闘にはしない。

## 2. 難易度プロファイル

既存倍率は互換性の基準として保持し、次の支援軸を追加する。最終値はプレイテストで調整するため、コードへ散在させず1つのプロファイルで管理する。

| 項目 | Easy | Normal | Hard |
|---|---|---|---|
| 敵耐久 / 火力 / 連射 / 攻撃性 / 自機耐久 | 現行Easyを開始値にする | 現行Normalを維持 | 現行Hardを維持 |
| 自動ターゲット | ON | 設定依存 | OFF |
| 照準アシスト | strong | light | off |
| ミサイルロック時間 | Normalの50〜70% | 現行基準 | 現行以上 |
| プレイヤーを同時攻撃する敵 | 最大1 | 最大2 | 制限なし |
| 敵射撃精度 | 低 | 現行基準 | 高 |
| ウェーブ開始 | 残存脅威が減るまで待つ | 定義どおり | 定義どおり |
| 失敗後の既定選択 | チェックポイント | ミッション再開 | ミッション再開 |

## 3. 照準アシストの制約

- プレイヤーが現在狙っているターゲットだけを補助する。
- 画面内かつリード点が照準補助範囲内にある場合だけ作動する。
- 補正量には毎秒上限を設け、急な機首移動を起こさない。
- プレイヤー入力と反対方向へ強制しない。
- 作動中はレティクル色/形状で明示する。
- `off` では演算結果が入力・弾道へ一切影響しないことをテストする。

## 4. チュートリアルの受け入れ基準

1. 初回起動後、訓練を開始するかスキップするか選べる。
2. 訓練では一度に1操作だけを求める。
3. 現在の入力方式に合わせて、マウスまたはキーを表示する。
4. 操縦、加速、ターゲット、主砲命中、ミサイル発射を実際の入力イベントで判定する。
5. 操作待ち中にプレイヤーが撃墜されたり、目標が先へ進んだりしない。
6. 5分以内に完了でき、完了後は通常ミッションへ自然に移る。

## 5. 手動E2Eチェックリスト

### マウスのみ

- [ ] タイトルで設定をクリックして開ける。
- [ ] 難易度、感度、Y反転を変更できる。
- [ ] 戻る→開始→ロードアウト→出撃をクリックだけで進める。
- [ ] マウス移動で任意方向へ旋回し、中央へ戻すと旋回が止まる。
- [ ] 左クリックで主砲、右クリックでロック済みミサイルを撃てる。
- [ ] ホイールで加減速できる。
- [ ] 1機撃墜し、結果画面をクリックして先へ進める。

### キーボードのみ

- [ ] 矢印/Tab/Enter/Space/Escで全UIを操作できる。
- [ ] 既存の飛行、射撃、ターゲット、僚機指令が動作する。
- [ ] Mでマウス操縦を切り替えられる。
- [ ] 高度な飛行OFF時にZを押してもNewtonへ切り替わらない。

### 状態遷移と安全性

- [ ] UI表示中のSpace/Enterで戦闘入力が発生しない。
- [ ] Pause中に機体が動かず、復帰直後に押下状態が残らない。
- [ ] blur/タブ移動/ウィンドウ外移動後に旋回・射撃し続けない。
- [ ] 設定変更がリロード後も保持される。
- [ ] 旧難易度設定と既存キャンペーンセーブを読み込める。
- [ ] ミッションへ5回再入場しても、1入力が複数回発火しない。

## 6. 数値で見る合格基準

- 初回プレイ相当で、訓練開始から5分以内に完了できる。
- Easyの通常任務で、開始から10分以内に最低1機撃墜できる。
- Easyの訓練中に、操作待ちが原因でミッション失敗しない。
- 入力から画面上の反応まで、通常フレームでは1フレームを超える意図的遅延を追加しない。
- 既存テスト＋新規テストがすべて成功し、本番ビルドが成功する。
- 代表戦闘で現行から明確なfps退行がなく、60fpsを目標とする。
