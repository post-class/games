# 操作と設定仕様

## 1. 互換性の考え方

今回の「Wing Commanderと同じ」は、原作の体験である「マウスで機首を向け、クリックで撃ち、キーボードで速度・兵装・ターゲットを操作できる」を既定プリセットとして提供することと定義する。

現行のキーボード操作は削除せず、別名キーを追加して後方互換を維持する。リポジトリ初期版READMEに記載されていた「マウス上下/左右で操縦、MでON/OFF」も復元する。

## 2. 既定操作

### 戦闘

| 操作 | マウス | キーボード |
|---|---|---|
| pitch / yaw | 画面中央からの上下 / 左右 | ↑↓←→ または W/S/A/D |
| roll | — | Q / E |
| スロットル増減 | ホイール上 / 下 | `+` / `-` または `]` / `[` |
| 0〜90%指定 | — | 0〜9 |
| 全速 / 全停止 | — | Backquote / Backspace |
| アフターバーナー | — | Tab（押下中） |
| 主砲 | 左ボタン（押下中） | Space（押下中） |
| ミサイル | 右ボタン | Enter |
| 次 / 最寄り / 前方ターゲット | — | T / R / Y |
| フレア / 副兵装切替 | — | C / X |
| マウス操縦切替 | — | M |
| Pause | — | Esc |
| 僚機命令 | — | `,` / `.` / `/` |

右ボタンはエッジ入力とし、1クリックで1発だけ要求する。ロックが必要な兵装は、未ロック時に発射せずHUDで理由を返す。

### メニュー

| 操作 | マウス | キーボード |
|---|---|---|
| 選択 | hover / click | 矢印 / Tab |
| 決定 | 左click | Enter / Space |
| 戻る | 戻るボタン | Esc / Backspace |
| スライダー | drag / click | 左右キー |

## 3. マウス仮想スティック

- 画面中央を原点とし、中央のデッドゾーン内は0、外側は距離に応じて最大1.0まで増加する。
- 画面上方向は機首上げを既定とする。`invertMouseY` で反転できる。
- X/Yの正規化はviewport寸法を使用し、リサイズ時に再計算する。
- 感度範囲は0.5〜2.0、既定1.0。最終値は必ず-1〜1にclampする。
- キーボード軸とマウス軸は加算後にclampする。反対入力が同時の場合は相殺を許容する。
- ポインターロックは必須にしない。将来追加する場合も、Escで即解除できること。

## 4. 入力コンテキスト

| コンテキスト | 戦闘軸/射撃 | UI操作 | マウスポインター |
|---|---:|---:|---|
| `combat` | 有効 | Pauseのみ | 仮想スティック＋戦闘ボタン |
| `menu` | 無効 | 有効 | 通常ポインター |
| `loadout` | 無効 | 有効 | 通常ポインター |
| `paused` | 無効 | 有効 | 通常ポインター |

コンテキスト切替時は、全押下状態、justPressed、マウスボタン、ホイール要求をクリアする。イベントリスナはアプリ全体で1組だけ登録し、コンテキストで振り分ける。

## 5. Settings v2案

```ts
interface GameSettingsV2 {
  version: 2;
  difficulty: "easy" | "normal" | "hard";
  controls: {
    preset: "wingCommander";
    mouseEnabled: boolean;
    mouseSensitivity: number;
    invertMouseY: boolean;
    advancedFlight: boolean;
  };
  assists: {
    aimAssist: "strong" | "light" | "off";
    autoTarget: boolean;
    contextualHints: boolean;
  };
  audio: {
    master: number;
    music: number;
    sfx: number;
  };
  tutorialCompleted: boolean;
}
```

既定値はEasy、Wing Commanderプリセット、マウスON、感度1.0、Y反転OFF、高度な飛行OFF、照準アシストstrong、自動ターゲットON、ヒントONとする。音量既定値は現行挙動を変えない値にする。

現行 `multidommander.settings.v1` の値が `easy | normal | hard` なら新設定の `difficulty` に引き継ぐ。キャンペーンセーブのキー/形式は変更しない。

## 6. 単一情報源

- アクション名、既定バインド、表示名を同じ定義に置く。
- 設定画面、HUDヒント、チュートリアル、README用の操作表は、その定義から取得する。
- `MissionScreens.ts` 等へキー名を再度ハードコードしない。
