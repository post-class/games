# Multi-Dommander

ブラウザで動く 3D 宇宙戦闘ゲーム。ウィングコマンダー系のドッグファイトを、ニュートン力学ベース（フライトアシスト切替つき）で再現した縦切りプロトタイプ。TypeScript + Three.js + 自作軽量 ECS。

## 起動

```bash
npm install
npm run dev      # http://localhost:5173/
```

その他:

```bash
npm run build    # 型チェック + 本番ビルド (dist/)
npm run preview  # ビルド結果をプレビュー
npm test         # ユニットテスト (vitest)
```

## 操作方法

ウィングコマンダー方式・**キーボードのみ**で操作します。

| 操作 | キー |
|---|---|
| 機首上げ / 下げ (ピッチ) | ↑ / ↓ (または W / S) |
| 左右旋回 (ヨー) | ← / → (または A / D) |
| ロール | Q / E |
| スロットル増減 | ] / [ |
| スロットル割合指定 | 数字 1〜9 (=10〜90%), 0 (=停止) |
| 全速 / 全停止 | ` (バッククォート) / Backspace |
| アフターバーナー (押し続け) | Tab |
| エネルギー砲 | Space |
| ミサイル発射 | Enter |
| 操作モード切替 (WC ⇄ ニュートン) | Z |
| 次のターゲット | T |
| 最至近ターゲット | R |
| 前方ターゲット | Y |
| 僚機: 編隊を組め | , (カンマ) |
| 僚機: 私の敵を攻撃 | . (ピリオド) |
| 僚機: 各自交戦 | / (スラッシュ) |
| 画面送り (タイトル/ブリーフィング/デブリーフ) | Enter |

- **MODE:WC (既定)**: ウィングコマンダー方式のアーケード飛行。機首を向けた方向へ飛ぶ（速度ベクトルが機首に追従）。スロットルで速度指定。キーボードで直感的に操作できる。
- **MODE:NEWTON**: 純慣性。推力を切っても等速直線運動を続けるリアルなニュートン挙動。Z キーで切替。
- スロットルはレバー式。キーを離しても値を保持する。

## ゲーム内容

タイトル → ブリーフィング → 出撃 → デブリーフ の流れで、3ミッションのキャンペーンを戦う。

- **キャンペーン**: 哨戒 → 護衛 → 強襲 の3ミッション。成功で次へ進み、失敗で再挑戦。分岐グラフ (`CAMPAIGN`) で管理し、進捗は自動で localStorage に保存される（タイトルで「続きから」）。
- **ミッション種別**: 全滅 (destroyAll)、護衛 (protect / 輸送艦を守る)、ナビ到達 (reachNav)、生存 (survive) をデータ駆動で定義。ウェーブ制の増援あり。
- **僚機 (ウィングマン)**: 味方機が同行して交戦。カンマ/ピリオド/スラッシュで編隊・攻撃・交戦を指示できる。
- **敵/味方AI**: 偏差射撃 (命中予測) を行う PD 制御のドッグファイト AI。
- **サウンド**: Web Audio API による合成効果音（発射・被弾・爆発・ミサイル）。音源ファイル不要。

HUD: シールド/アーマー/ハル、スロットル/速度、エネルギー/ミサイル残弾、ミッション目標、ターゲット情報、リードインジケータ（命中予測）、画面外ターゲット/ナビ矢印、レーダー（敵=赤/味方=緑）、アナウンス表示。

## アーキテクチャ

```
src/
├── ecs/          自作軽量 ECS (World / Component / System)
├── game/
│   ├── Game.ts          固定dt物理 + 可変dt描画ループ (Fix Your Timestep)
│   ├── GameController.ts 進行統括 (タイトル→ブリーフィング→出撃→デブリーフ→分岐)
│   ├── GameState.ts      フェーズ/結果/撃墜数
│   ├── SaveManager.ts    localStorage セーブ
│   ├── AudioManager.ts   Web Audio 合成効果音
│   ├── factions.ts       陣営の敵対判定
│   ├── components.ts     全コンポーネント定義
│   ├── systems/          Input/Flight/Weapon/Projectile/Missile/Collision/
│   │                     Damage/Targeting/AI/Mission/Sync/Hud/Explosion
│   ├── mission/          ミッション定義データ + MissionManager (ウェーブ/目標/勝敗)
│   ├── ships/            データ駆動の機体定義 + ファクトリ
│   ├── weapons/          弾/ミサイル生成
│   ├── ui/               タイトル/ブリーフィング/デブリーフ画面
│   └── input/            入力集約 + マウスジョイスティック
├── render/       Three.js シーン / メッシュ生成 (GLTF差替口) / カメラ / 星空
├── hud/          DOM+CSS の HUD, リード計算, レーダー
├── util/         数学ヘルパー, イベントバス
└── config/       物理・入力バインドのチューニング値
```

- **物理**: 6DOF。姿勢はクォータニオン。`MODE:WC` は速度が機首方向へ追従するアーケード飛行、`MODE:NEWTON` は純慣性。物理エンジンは非使用。
- **衝突**: 弾は前フレーム→現フレームの線分-球スイープ（高速弾のすり抜け対策）。
- **AI**: `Idle → Pursue → Attack → Evade` の FSM + 偏差射撃 (PD 制御で機首を予測点へ)。プレイヤー/敵/僚機すべて同じ `ThrusterInput` を生成し飛行制御を共通化。
- **ミッション**: `mission/missions.ts` にデータ駆動で定義（ウェーブ/目標/分岐）。`MissionManager` が実行時状態を管理。
- **アセット**: 既定はプログラマアート（プリミティブ）。`ShipDefinition.visual.kind` を `gltf` にし `gltf.url` を指定すれば `MeshFactory` が非同期ロードして差し替える（失敗時はフォールバック形状）。

## テスト

`npm test` で 30 件のユニットテスト（物理積分・ピッチ規約・リード予測・ダメージ・衝突・ミッション目標・キャンペーングラフ）。
