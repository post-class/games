# E2Eテスト観点（2026-08-11）

対象: `multi-taktika/game`（Vite開発サーバー、Chrome DevTools MCP）

## 対象画面

| 区分 | 画面 | 確認内容 |
|---|---|---|
| 試合前 | タイトル | 主要導線、設定、クレジット、視認性 |
| 試合前 | 対戦設定 | 8種マップ、開始時代、開始資源、速度、人口上限、シード、参加者、準備、開始 |
| 試合前 | 文明選択 | 8文明、ランダム、戻る、決定、文明詳細 |
| 試合前 | キャンペーン | 章・ミッション選択、ロック表示、開始、記録消去、戻る |
| 試合中 | 対戦画面 | HUD、戦域スロット、コマンドグリッド、警告、時間進行、負荷入口 |
| 試合中 | 戦域指令ビュー | Tab、戦域選択、令カード表示・選択、閉じる |
| 試合中 | 試合メニュー | F10、Pause、一時停止／再開、設定、投了、退出 |
| 試合後 | 結果 | リプレイ、再戦、タイトルへの導線（開発用直接遷移を含む） |
| 試合後 | リプレイ | 再生、一時停止、前後の令、倍速、視点、レーン選択 |
| 設定 | 設定 | プリセット、キー再割り当て、チェックボックス、速度、標準化、戻る |

## 操作観点

- マウス: 全画面の主要ボタン、選択状態、無効状態、戦域／令カードのクリック。
- キーボード: `Tab`、`Shift+1`、`F10`、`Pause`、`Esc`、設定画面のキー表示。
- 入力値: `<select>` の変更、シード入力、ゲーム速度スライダー、チェックボックス。
- 状態遷移: タイトル → 対戦設定 → 準備完了 → 対戦、試合中のオーバーレイ開閉。
- 表示: 全画面キャプチャ、a11yスナップショット、HUDの数値・ボタン状態。
- シナリオ: 試合設定を変更して開始し、設定値がゲーム初期状態へ反映されること。
- 異常系: 開発用パラメータで結果・リプレイを直接開いた場合の空状態表示。

## 除外

決定論、戦闘計算、経済計算、データ整合性など、テストコードで完結する単体・決定論テストはE2E対象外とする。ただし、画面からシムへ設定が渡る結線はE2Eで確認する。
