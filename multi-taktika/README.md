# Multi-Taktika

一つの海を、八つの文明が囲んでいる ―― ブラウザで動く決定論リアルタイムストラテジー。

**部隊を直接動かさない RTS** です。プレイヤーは総大将で、戦場に立った「戦域」ごとに
**令（れい／Taktika）を 1 枚渡す**ことしかできません。令は旗鼓と伝令で届くので、
出した瞬間ではなく**届いた瞬間**に効きます。タイトルの Multi-Taktika は
「複数の令を同時に運用すること」を指します。

- 8 文明・4 つの世（黎明・青銅・鉄器・帝国）・1 試合 30 分
- 1 人（AI 5 段階）／オンライン最大 8 人（1 対 1 〜 4 対 4）／キャンペーン全 4 章
- アカウント登録なし。URL を共有すれば同じ部屋に入れる

## 動かす

```bash
cd game
npm install
npm run dev          # 開発サーバ（http://localhost:5173）
```

オンライン対戦を試すときは中継サーバも起動する（入力を配るだけで、勝敗は計算しない）:

```bash
npm run server
```

開発している環境は **Node 24.11.1 / npm 11.12.1** です。
中継サーバは `node --experimental-strip-types` で TypeScript を直接読ませているので、
このフラグが使える Node が要ります（`package.json` に `engines` は書いていないので、
古い Node でも `npm run dev` までは動く可能性があります ―― 未検証）。

### 開発中に使える入口

| URL | 何が出るか |
|---|---|
| `/` | タイトル |
| `/?dev=<画面 ID>` | その画面を直接開く（`match` `campaign` `replay` `settings` など） |
| `/?stress=400` | 兵 400 体を撒く（性能の確認用。タイトルから対戦を始めると効く。実測 438 体 / 120fps） |
| `/#room=<部屋名>` | オンライン対戦（中継サーバが要る） |

## 検証

```bash
cd game
npm run check        # typecheck → lint → test（これが通れば壊していない）
npm test             # テストだけ
npm run test:golden  # 代表 3 試合のリプレイ回帰
```

`npm run check` が通ることを、変更のたびに確認してください。
**ゴールデンリプレイが落ちたときは、まず `tests/golden/golden.replay.test.ts` の
冒頭を読んでください**（`npm run golden:rebase` を打つ前に読むべき判断基準が書いてあります）。

## この設計で外してはいけないこと

### 1. 決定論

同じ入力を同じ順序で与えれば、どの端末でも必ず同じ試合になります。
対戦同期・リプレイ・観戦・AI 代行はすべてこの 1 つの性質に乗っています。

- 1 秒 = **25 tick**、30 分 = 45,000 tick。座標は送らず**入力だけ**を交換する
- 座標も体力も**固定小数（Q8）の整数**。`Math.random` / `Date.now` / `performance.now` /
  浮動小数は `sim` では使わない（ESLint が弾く）
- 乱数は `world.rngCombat` / `rngAi` / `rngMap` の 3 系統（用途を混ぜると再現しない）
- エンティティの走査は**必ず index 昇順**。同値のときの順序まで決める
- 250 tick ごとに世界のハッシュを突き合わせて、ずれたら止める

### 2. 層

```
sim ← render / ui / input / ai / net / replay / audio
```

矢印の向きだけが許されます。**`sim` は他の層を import できません**（ESLint 設定で禁止）。
`sim` を変える唯一の道は `Command` で、tick の頭に playerId 昇順で渡します。

### 3. AI はズルをしない

AI は `World` ではなく **`AiView`**（そのプレイヤーに見えているものだけ）を受け取ります。
渡していないものは読めないので、視界の透視や資源の増量が構造的に起こりません。
難易度で変わるのは**判断の速さと使える仕組みの範囲**だけです。

### 4. 数値をコードに書かない

バランスに関わる数値はすべて `game/src/data/*.json` にあります。
コードからは `cfgNum` / `cfgInt` / `cfgAges` などで引き、**キーが無ければ例外**にします
（既定値で黙って動くと、設定が効いていないことに誰も気付けません）。

## ディレクトリ

```
game/src/
  sim/        試合の計算（決定論。ここだけで勝敗が決まる）
    core/     計算の部品（純関数寄り。テストしやすい単位）
    systems/  毎 tick の状態遷移 14 本
  render/     Canvas 2D の描画・視界・スプライト
  ui/         HUD と 13 画面
  input/      キーボード・マウス・カメラ
  ai/         AI（`AiView` しか読まない）
  net/        ロックステップ同期
  replay/     録画と再生
  audio/      効果音（音源が無ければ波形を合成して鳴らす）
  data/       すべての数値（JSON）
  campaign/   キャンペーン
game/tests/
  unit/         単体
  determinism/  同じ入力 → 同じハッシュ
  golden/       代表試合のリプレイ回帰
  balance/      文明バランス・テンポ・APM の実測
  perf/         1 tick の予算（4ms）

server/         オンライン対戦の中継
```

## 資料と記録

**仕様は `docs/*.html` が唯一の出どころ**です。実装で迷ったらここに戻ってください。

| 資料 | 内容 |
|---|---|
| `docs/01_ゲーム宣伝.html` | 何が面白いゲームなのか |
| `docs/02_世界観.html` | 環海と八国。**固有ボーナスの根拠はここ**（土地の事情から導いている） |
| `docs/03_文明と進化.html` | 文明・兵・建物・研究・進化条件 |
| `docs/05_画面説明.html` | 13 画面 |
| `docs/06_操作方法.html` | 操作と令の渡し方 |
| `docs/07_ゲームシステム.html` | 戦域・令・視界・経済・AI・通信 |

作業の記録は次の 4 つです。**中断しても再開できるように書いてあります**。

| 記録 | 内容 |
|---|---|
| `docs/PROGRESS.md` | 実装台帳（189 項目）と**次にやるべきこと** |
| `docs/ISSUES.md` | つまずきと**教訓**。同じ失敗を繰り返さないための本体 |
| `docs/BALANCE.md` | バランスの実測。数字を動かす前に読む |
| `docs/DOD.md` | 完了条件 9 項目と測り方 |

### 先に読むと得をするもの

`docs/ISSUES.md` には「**仕組みはあるのに使われていない**」種類の不具合が
繰り返し記録されています（効果適用エンジンの未結線、効果音の呼び出し口が 1 つだけ、
資源の絵を探す口はあるのに絵が無い、など）。いずれも単体テストは全部緑のままでした。

そこから来ている検証の作法は 3 つです。

1. **呼び出し箇所を grep して数える。** 0 件や 1 件なら、それは未実装と同じ
2. **8 文明の終局状態を並べる。** 同じ数字が並んだら、その仕組みは効いていない
3. **端から端までのテストを 1 本置く。** 計算のテストは結線を保証しない

## いまの状態

実装は M0〜M18 を走り切り、タイトル → 対戦 → 結果 → リプレイ →
キャンペーン → オンラインが通ります。完了条件は 9 項目中 8 達成。

残っているものと優先順は `docs/PROGRESS.md` の「次にやるべきこと」にあります
（いちばん効くのは **AI が拠点周辺の森を伐り尽くしたあとの木材収入**で、
そこが試合の決着・帝国の世への到達・文明バランスの測定すべての律速になっています）。

## アセット

絵と音は `tools/assets` で作ります。**プロンプトはマスターデータから機械的に組む**ので、
ユニットや建物が増えても絵柄が揺れません。

```bash
uv run python tools/assets/build.py plan --only units   # 何を作るか見る（API を叩かない）
uv run python tools/assets/build.py gen  --only units --parallel 10
uv run --with pillow python tools/assets/build.py post   # 透過整形して public/assets へ
uv run --with pillow python tools/assets/build.py pack   # アトラスと manifest
```

生成済みのものは飛ばすので、途中で止めても再開できます。
**絵が無くても遊べます**（図形で代替する）。効果音も音源ファイルが無ければ
波形を計算して鳴らすので、無音にはなりません。
