## 注記

### #2「30 分試合」について

一周は**実機で通した**が、通したのは投了による決着（0:41）で、
**30 分を人間が遊び切った通しではない**。30 分ぶんのシムは
`tests/determinism/lockstep.test.ts`（45,000 tick）と
`tests/balance/tempo.test.ts`（45,000 tick）で回しており、
シム・通信・リプレイの側は 30 分を通しても壊れないことを確認している。

### #7「統合 GPU ノート」について — これだけ未検証

手元の実測は余裕（120fps / 描画 0.5ms / 予算 10ms に対し 5%）だが、
**測ったのはこの開発機であって、条件に書かれた統合 GPU のノートではない**。
「余裕が 8 倍あるから大丈夫だろう」は測ったことにならないので未検証とする。

測るときの手順:
1. `npx vite build && npx vite preview --port 5188`
2. 対象機のブラウザで `http://<開発機の IP>:5188/?dev=match&stress=400`
3. 画面下端のデバッグ行の `fps` と `描画` を読む（60fps / 描画 10ms 以内なら満たす）
4. 足りない場合に見るのはこの順: `描画` の内訳（`地形` `霧` `兵`）→
   `src/render/spriteLayer.ts` の間引き → `terrainCache` のチャンクサイズ
